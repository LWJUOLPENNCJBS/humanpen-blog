進 flag 通話前先打開 export

Charles Li / HumanPen

先點加入再找檔案，會烧掉會議裡僅有的安靜一分鐘。

本條延續檢測器報告素養。它不承諾過檢。它只要求進房前先打開 export。

為什麼檔案先於攝影機

先在螢幕上核對 attempt ID 與頁數，再點加入。通話從邀請裡點名的同一份材料開始。

準備是後勤，不是裁決。

四步

  1. 1. 用邀請裡的 URL 打開入口 export。
  2. 2. 對自己讀一遍 attempt ID。
  3. 3. 保持該視窗置頂再加入通話。
  4. 4. 從不售賣保證過檢。

HumanPen

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住

  • 加入前先開 export
  • 核對 attempt ID
  • 以邀請 URL 為準
  • HumanPen 是流程助手，不是通行證
