Stamp the folder date before you escalate a detector flag

Charles Li / HumanPen

Screenshots pile up without a home. An undated desktop heap makes it hard to prove which attempt anyone discussed.

This note continues detector-report literacy. It does not promise clearance. It asks for a dated folder stamp before escalation.

Why the folder stamp comes first

Name the folder YYYY-MM-DD + attempt ID. Drop the full export inside before any forward. Keep the syllabus clause PDF beside it if you will meet.

Folders are for logistics—not for verdicts.

Four steps

  1. 1. Create folder: date + attempt ID.
  2. 2. Save full export (and tool/version note) into it.
  3. 3. Add syllabus/rubric only if needed for the meeting.
  4. 4. Escalate with a link to that folder—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: date-stamp the folder; badge is not a verdict.

Remember

  • Dated folder with attempt ID
  • Export inside before escalate
  • Screenshot secondary
  • HumanPen is workflow help, not a pass
