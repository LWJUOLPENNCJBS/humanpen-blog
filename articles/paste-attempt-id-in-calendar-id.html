Tempel attempt ID ke undangan kalender untuk rapat flag

Charles Li / HumanPen

Undangan tanpa attempt ID memaksa semua orang menebak ekspor mana yang dibuka.

Catatan ini melanjutkan literasi laporan detektor. Tidak menjanjikan kelulusan. Meminta Anda menaruh attempt ID di isi undangan.

Mengapa baris kalender dulu

Salin ID dari ekspor portal ke deskripsi undangan, dan simpan URL ekspor di baris berikutnya.

Baris kalender adalah logistik—bukan vonis.

Four steps

  1. 1. Salin attempt ID dari ekspor.
  2. 2. Tempel ke isi undangan kalender.
  3. 3. Tambahkan URL ekspor di bawahnya.
  4. 4. Jangan jual jaminan lulus.

HumanPen

HumanPen (https://humanpen.net) dapat menunjukkan impor laporan dan mengedit span bertanda sambil menjaga sitasi. Tidak menjual peringkat atau kelulusan.

Ingat: attempt ID di undangan; lencana bukan vonis.

Remember

  • ID di isi kalender
  • URL ekspor di bawahnya
  • Screenshot sekunder
  • HumanPen bantuan alur kerja, bukan tiket lulus
