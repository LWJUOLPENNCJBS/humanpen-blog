Park off-topic threads before you return to the agenda

Charles Li / HumanPen

Side debates steal the clock and blur who owns what. When a thread drifts, write it on a short parking-lot list, then return to the agenda—so action owners stay clear. In flag review, that means: don’t chase side debates until the attempt ID and export window are settled.

This is distinct from label-owner-on-each-action, from schedule-followup-before-leave, from write-meeting-takeaways, from mute-chat-during-flag-review, from confirm-attempt-id-first, and from pin-export-window-during-review. Here the literacy move is concrete: park the off-topic line, then resume the planned agenda.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Name the agenda in one line (e.g. confirm attempt ID → open export → list flagged spans).
  2. When talk drifts (“what if another detector…”, “my roommate’s case…”), write a one-line park item.
  3. Say aloud: “Parking that—back to attempt ID / export.”
  4. Finish the agenda; only then triage the parking lot (keep, schedule, or drop).
  5. Assign owners only to kept items—not to every tangent that appeared mid-call.

Why parking keeps owners clear

Tutors in India and Southeast Asia English-medium programs run short slots. An unparked tangent turns “who rewrites §3” into three parallel debates. A parking lot protects the export-window agenda so named actions still make sense at the end.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a brush-off of real concerns—parked items get a timed look after the agenda.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report once your flag-review agenda has settled attempt ID and export—before side debates. No guaranteed next percentage.

Remember

  • Park off-topic; return to the agenda.
  • Settle attempt ID / export before side debates.
  • Triage the parking lot after—not during—the core review.
  • Honest tools do not promise a clean next card.
