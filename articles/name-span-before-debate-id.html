Sebut rentang sebelum berdebat soal skor

Charles Li / HumanPen

Persen tanpa rentang mengubah rapat menjadi tebak-tebakan.

Catatan ini melanjutkan literasi laporan detektor. Ia tidak menjanjikan kelulusan. Ia meminta Anda menyebut rentang sebelum berdebat soal skor.

Mengapa rentang lebih dulu

Baca attempt ID, lalu sebut sorotan mana. Baru kemudian bahas suntingan.

Naming spans is logistics—not a verdict.

Steps

  1. 1. Salin attempt ID dari ekspor.
  2. 2. Tunjuk rentang dan nomor halaman.
  3. 3. Debatkan suntingan—bukan hanya lencana.
  4. 4. Jangan menjual jaminan lolos.

HumanPen

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: name the span first; badge is not a verdict.

Remember

  • Rentang disebut dulu
  • Nomor halaman diucapkan
  • Skor sekunder
  • HumanPen adalah bantuan alur kerja, bukan izin lewat
