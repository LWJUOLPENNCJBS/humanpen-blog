裁切图常藏起导师要的 attempt ID

Charles Li / HumanPen

聊天里裁切的 AI 徽章图，通常只剩百分比。办公室谈话真正需要的字段——attempt / submission ID、导出时间、检测器名称/版本、完整高亮上下文——常常被裁掉或根本不在画面里。

这与「截图不是案卷」不同。这里的失败更窄：裁切藏起了身份字段，导师无法把徽章对上 LMS 那一行。

本文是检测器报告素养。不承诺分数，也不是规避指南。

裁切常见缺什么

  • 门户卡片或报告页眉上的 attempt / submission ID。
  • 导出或生成时间戳。
  • 是哪家检测器（及版本）给出的徽章。
  • 色块以外的完整连续正文高亮。

没有这些，印度与东南亚英授项目的导师无法判断你在争 Attempt 1 还是 Attempt 2，甚至是不是另一份文件。

优先带这套

  1. 完整检测导出 PDF（或官方门户下载）。
  2. 从 LMS 行抄下的门户 attempt / submission ID。
  3. 同一 attempt 对应的草稿（带日期副本或版本史）。
  4. 若必须发手机图，请带上显示 ID 的页眉——不要裁掉。

这不是什么

  • 不保证下一张徽章会清零。
  • 不是建议拒绝学校已要求的截图。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持对照完整报告处理文档并保留引用与排版——适合在身份字段可见且对齐时准备谈话。不保证下一个百分比。

记住

  • 裁切 ≠ 身份包。
  • Attempt ID + 时间戳 + 完整 PDF > 裁切徽章色块。
  • 先对齐 LMS 行，再争论数字。
  • 诚实工具不承诺下一张干净卡片。
