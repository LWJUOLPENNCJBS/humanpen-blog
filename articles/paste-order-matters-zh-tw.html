貼上順序要緊：先交完整稿再讀報告，入口截圖不能代替 PDF

Charles Li / HumanPen

群聊常把流程反著來：先截 LMS入口徽章爭數字，再貼半篇稿——或逐段貼上「試一試」。貼上順序要緊。多數學校流水線是先把一次提交 attempt 當成一份檔案（或一次完整貼上）再出報告。讀仍在處理的卡片，或入口裁圖，不等於讀官方 PDF 匯出。

本文是檢測器報告素養。不承諾分數，也不是規避指南。

為什麼順序會打斷證據鏈

半截貼上、事後補附錄、處理中途截圖，都會讓徽章描述的不是最終 attempt。印度與東南亞學生常分享入口磁貼，而 PDF 仍在產生——或根本不下 PDF。指導老師於是爭論一個從未對應穩定檔案身分的數字。

入口截圖通常沒有圖例、信心帶、頁級高亮與腳註。PDF（或工具內完整報告）才是證據包；磁貼只是入口。

更穩的順序

  1. 先湊齊你打算提交的完整稿（含你真正會保留的文前部分）。
  2. 作為學校將評分的那次 attempt 一次上傳／貼上；記下檔名與時間戳。
  3. 等處理結束；下載官方報告／PDF。
  4. 然後才分流高亮——不要只憑入口裁圖改寫。

不要做什麼

  • 不要在正式評分 attempt 裡逐句貼上「實驗」。
  • 不要把 WhatsApp 入口截圖當報告。
  • 不要在 attempt ID 與匯出未對齊時拿同學磁貼比較。

HumanPen

有了穩定的完整報告匯出後，HumanPen（humanpen.net）可幫你改 flagged 段並保留引用與排版。它不替代「先交完整稿」，也不保證下一張徽章。

記住

  • 完整稿 → 穩定 attempt → 完整 PDF → 再分流。
  • 入口截圖 ≠ PDF 證據包。
  • 貼上順序決定估計器實際看到哪些文本。
  • 誠實工具不承諾下一張乾淨卡片。
