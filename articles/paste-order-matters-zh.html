粘贴顺序要紧：先交完整稿再读报告，门户截图不能代替 PDF

Charles Li / HumanPen

群聊常把流程反着来：先截 LMS门户徽章争数字，再粘半篇稿——或逐段粘贴「试一试」。粘贴顺序要紧。多数学校流水线是先把一次提交 attempt 当成一份文件（或一次完整粘贴）再出报告。读仍在处理的卡片，或门户裁图，不等于读官方 PDF 导出。

本文是检测器报告素养。不承诺分数，也不是规避指南。

为什么顺序会打断证据链

半截粘贴、事后补附录、处理中途截图，都会让徽章描述的不是最终 attempt。印度与东南亚学生常分享门户磁贴，而 PDF 仍在生成——或根本不下 PDF。导师于是争论一个从未对应稳定文件身份的数字。

门户截图通常没有图例、置信带、页级高亮与脚注。PDF（或工具内完整报告）才是证据包；磁贴只是入口。

更稳的顺序

  1. 先凑齐你打算提交的完整稿（含你真正会保留的文前部分）。
  2. 作为学校将评分的那次 attempt 一次上传/粘贴；记下文件名与时间戳。
  3. 等处理结束；下载官方报告/PDF。
  4. 然后才分流高亮——不要只凭门户裁图改写。

不要做什么

  • 不要在正式评分 attempt 里逐句粘贴「实验」。
  • 不要把 WhatsApp 门户截图当报告。
  • 不要在 attempt ID 与导出未对齐时拿同学磁贴比较。

HumanPen

有了稳定的完整报告导出后，HumanPen（humanpen.net）可帮你改 flagged 段并保留引用与排版。它不替代「先交完整稿」，也不保证下一张徽章。

记住

  • 完整稿 → 稳定 attempt → 完整 PDF → 再分流。
  • 门户截图 ≠ PDF 证据包。
  • 粘贴顺序决定估计器实际看到哪些文本。
  • 诚实工具不承诺下一张干净卡片。
