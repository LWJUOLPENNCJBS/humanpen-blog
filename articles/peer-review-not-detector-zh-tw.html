同伴互評不是檢測分——兩者不能互相替代

Charles Li / HumanPen

把同伴評語和檢測百分比攪在一起，會把兩件事打成一場架。互評問主張是否站得住；徽章問閾值偏好哪一類。

本文延續檢測器報告素養。它不承諾過檢。它要求同一張表上分兩欄。

為什麼要兩欄

export 帶上 attempt ID 與 coverage。若工具分歧，保留兩份帶日期檔案。若隨後改寫，保留引用。

不要把弱互評當成 AI 寫作證據——也不要把低徽章當成互評成績。

四步

  1. 1. A 欄：同伴對論證與文獻的評語。
  2. 2. B 欄：帶 attempt ID 的檢測 export。
  3. 3. 把工具分歧記為公正訊號。
  4. 4. 下一步按流程——從不推銷保證過檢。

HumanPen 與記住

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯 flagged span。它不賣排名或過檢。

記住：兩欄、兩件事、一次公平約談。
