回复 flag 邮件前先收藏门户 export URL

Charles Li / HumanPen

Flag 邮件常只带裁切截图。只凭图片回复，会丢掉 attempt ID 与实时 export 链接。

这篇延续检测器报告素养。它不承诺过检。它只要求：回复前先收藏门户 export URL。

为什么先收藏

打开门户，打开被打分的 attempt，复制 export URL，用 attempt ID 命名浏览器书签。回复附上该 URL——不要用手机拍徽章。

书签用来对齐流程——不是下判词。

四步

  1. 1. 在 flag 邮件旁打开门户。
  2. 2. 打开邮件点名的那一次 attempt。
  3. 3. 收藏 export URL（用 attempt ID 命名）。
  4. 4. 回复附上该书签——从不售卖保证通过。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：先收藏 export URL；徽章不是判词。

Remember

  • 书签含 attempt ID
  • 回复附实时 export URL
  • 截图只作辅证
  • HumanPen 是流程助手，不是通行证
