手机截图不是违纪案卷

Charles Li / HumanPen

AI writing 百分比或徽章一出来，学生常把手机屏幕拍下来丢进微信/WhatsApp。那张图感觉像证据。办公室谈话里通常不是。徽章的手机截图不是违纪案卷。

本文是检测器报告素养。不承诺分数，也不是规避指南。

截图通常缺什么

裁切图只显示数字或色块。很少能看到完整连续正文高亮、检测器名称与版本、提交/attempt ID、导出时间，以及教师视图与学生视图是否一致。导师无法把你的草稿对上一条聊天气泡裁切。

印度与东南亚学生常因只带「刷屏图」、不带学校实际入库的门户导出而失分。

该带什么

  1. 完整检测导出 PDF（或官方门户下载），不是手机裁切。
  2. 与 LMS 行一致的 attempt / submission ID。
  3. 同一 attempt 对应的草稿痕迹（带日期副本或版本史）。
  4. 简短说明：哪些 flagged 连续正文你能解释。

这不是什么

  • 不保证下一张徽章会清零。
  • 不是建议隐瞒学校已要求的截图。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持对照完整报告做文档级处理并保留引用与排版——适合用真实导出准备办公室谈话，而不是聊天裁切。不保证下一个百分比。

记住

  • 截图 ≠ 案卷。
  • 完整 PDF + attempt ID + 草稿痕迹 > 裁切百分比。
  • 全部对齐同一提交。
  • 诚实工具不承诺下一张干净卡片。
