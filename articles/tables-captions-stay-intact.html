Keep tables and captions intact while you rewrite flagged prose

Charles Li / HumanPen

Flattening a results table into chat text often breaks column labels the detector never scored.

This note is detector-report literacy for HumanPen document polish. It does not promise clearance or an undetectable rewrite. It asks you to keep tables and captions intact.

Structure is part of the evidence

Freeze table cells, captions, citations, and numbers. Soften only continuous flagged prose; export so layout comes back.

Badge is not a verdict—keep the grid the report never scored.

Steps

  1. Import the Turnitin / iThenticate-style export.
  2. Leave tables and captions frozen.
  3. Rewrite flagged continuous prose only in HumanPen.
  4. Never sell a guaranteed pass.

HumanPen

HumanPen (https://humanpen.net) helps import a detection report and rewrite flagged spans while tables, captions, and layout stay intact. It does not sell rankings or clearance.

Remember

  • Citations and numbers frozen
