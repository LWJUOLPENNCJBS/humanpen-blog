Bring the same file to the meeting as the scored attempt

Charles Li / HumanPen

Office hours go sideways when you open a newer local rewrite while the tutor’s portal still shows the older file that produced the scored attempt ID. They highlight spans you “already fixed”; you look defensive; the meeting burns.

This is distinct from confirming the attempt ID first, from a general office-hours version check, from keeping a human edit trail, from email-badge vs portal, from asking for the full export, from reading the syllabus AI clause before weaponizing a score, and from stamping a timestamp before rewrite. Here the rule is concrete: bring the same file/PDF that matches the scored attempt—not the post-report draft on your laptop.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Confirm the attempt ID on the export or portal card.
  2. Download or reopen the exact submission file that attempt scanned (LMS version / timestamp / filename).
  3. Bring that file (and the full export) to the meeting—open it side by side with the report.
  4. Keep any newer rewrite in a separate folder; label it clearly as post-report.
  5. Only after the meeting, decide whether to resubmit a revised draft under policy.

Why mismatched files fail

Tutors in India and Southeast Asia English-medium programs open the portal attempt you were scored on. If your screen shows different paragraphs, they cannot verify authorship claims or walk flagged spans with you. A polished laptop draft does not replace the scored file for that conversation.

What this is not

  • Not a guarantee the next badge will clear.
  • Not advice to hide that you edited afterward—say so, with a short change note.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report once you are working from the right attempt file. No guaranteed next percentage.

Remember

  • Same file as the scored attempt ID → meeting.
  • Newer local rewrite ≠ the file the tutor sees.
  • Export + matching submission side by side.
  • Honest tools do not promise a clean next card.
