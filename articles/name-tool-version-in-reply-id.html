Sebutkan nama dan versi alat detektor dalam balasan flag

Charles Li / HumanPen

Balasan yang hanya bilang “skornya tinggi” membuat semua orang menebak alat dan build mana yang membuat lencana.

Catatan ini melanjutkan literasi laporan detektor. Tidak menjanjikan kelulusan. Meminta Anda menamai alat + versi dalam balasan.

Mengapa alat dan versi dulu

Tulis nama produk dan string versi/build di ekspor. Tempel URL ekspor di samping baris itu. Screenshot tanpa teks versi bersifat sekunder.

Menamai alat adalah logistik—bukan vonis.

Empat langkah

  1. 1. Buka ekspor; salin nama alat + versi.
  2. 2. Tulis keduanya di baris pertama balasan.
  3. 3. Lampirkan atau tautkan ekspor penuh.
  4. 4. Jangan jual jaminan lulus.

HumanPen dan ingat

HumanPen (https://humanpen.net) dapat menunjukkan impor laporan dan mengedit span bertanda sambil menjaga sitasi. Tidak menjual peringkat atau kelulusan.

Ingat: sebutkan alat + versi; lencana bukan vonis.

Remember

  • Nama alat + versi di baris satu
  • URL ekspor di sampingnya
  • Screenshot sekunder
  • HumanPen bantuan alur kerja, bukan tiket lulus
