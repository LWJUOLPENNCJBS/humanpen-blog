把 attempt ID 贴进 flag 会议的日历邀请

Charles Li / HumanPen

邀请里没有 attempt ID，大家只能猜该打开哪份 export。

这篇延续检测器报告素养。它不承诺过检。它只要求：把 attempt ID 写进邀请正文。

为什么先写日历行

从门户 export 复制 ID 到邀请描述，下一行放 export URL。

日历行是流程对齐——不是下判词。

Four steps

  1. 1. 从 export 复制 attempt ID。
  2. 2. 贴进日历邀请正文。
  3. 3. 下一行附上 export URL。
  4. 4. 从不售卖保证通过。

HumanPen

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：邀请里写 attempt ID；徽章不是判词。

Remember

  • 日历正文含 ID
  • 下附 export URL
  • 截图只作辅证
  • HumanPen 是流程助手，不是通行证
