Match the rewrite to the report’s highlighted span

Charles Li / HumanPen

On humanpen.net, the rewrite target should be the same passage the Turnitin / iThenticate AI report highlighted—not the clean sentence next to it, and not an entire paragraph wash “just in case.” HumanPen is built to import the report and work against those flagged continuous-prose spans.

That complements import-report-rewrite-flagged-only (report drives targeting), only-flagged-continuous-prose (scope = flagged continuous prose), leave-unflagged-prose-alone (clean spans stay), and recheck-after-detector-update (fresh report after vendor change). It differs from flagged-passages-first (priority order), dont-wash-whole-document (anti whole-file wash), freeze-citations-numbers-formulas / preserve-reference-list (fidelity freezes), and pay-by-rewritten-words (billing unit). This note names span matching: highlight boundaries → rewrite those boundaries.

No promised next AI%. No “bypass detector” or “undetectable” claim. School policy still owns clearance.

Why span matching matters

  1. Neighboring clean prose was not the flagged unit—rewriting it wastes effort and can create new Similarity or style noise.
  2. Whole-paragraph wash “for safety” is the failure mode honest tools reject.
  3. Report highlights are the shared map between you, the tool, and a later re-check.
  4. Misaligned rewrites make free-round / re-import loops harder to interpret.
  5. Document-level revision only works if the meter and the freeze list track the same spans the report marked.

Practical workflow (aligned with HumanPen)

  1. Import the AI writing report into HumanPen; confirm attempt identity and coverage.
  2. Read the highlights first—note start/end of each flagged continuous-prose span.
  3. Rewrite only those spans; leave neighboring unflagged sentences, citations, numbers, formulas, and layout alone.
  4. Export and spot-check: changed text sits inside the old highlight bounds, not beside them.
  5. Re-import a fresh report for the next round; free rounds (if any) still apply only to still-flagged prose under the homepage framing.

What this is not

  • Not a guarantee the next AI% or Similarity % will drop or clear school policy.
  • Not permission to expand the rewrite into unflagged neighbors “to be safe.”
  • Not “undetectable,” bypass, or advice to hide authorship.
  • Not a substitute for import-report-rewrite-flagged-only on targeting, or for leave-unflagged-prose-alone on clean spans.

Where HumanPen fits

HumanPen at humanpen.net is a document-level AI revision tool: import the report, rewrite flagged continuous prose, preserve citations and layout where possible, bill by rewritten words, and offer free rounds on remaining flags under the homepage framing. Matching the rewrite to the report span is part of that honesty—not an optional extra.

Remember

  • Rewrite the highlighted span—the same passage the report flagged.
  • Not the neighboring clean sentence; not a whole-paragraph wash.
  • Complements import-report-rewrite-flagged-only, only-flagged-continuous-prose, leave-unflagged-prose-alone, recheck-after-detector-update.
  • Honest tools do not sell “bypass” or “undetectable.”
