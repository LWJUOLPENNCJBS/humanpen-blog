爭論片段前，先禮貌索取完整檢測匯出

Charles Li / HumanPen

有時收件匣裡只有裁切徽章或郵件百分比。僅憑這些爭論「哪句標錯了」通常無效——導師依據的是某次 attempt ID 的完整檢測器匯出 PDF，不是縮圖。

這與「截圖≠案卷」、與裁切藏掉 attempt ID、與郵件徽章 vs 入口報告、與先確認 attempt ID、與兩份匯出並排、與改寫前蓋時間戳、與不要只改引言都不同。這裡的動作很具體：爭論片段前，先索取該次 attempt 的完整匯出 PDF。

本文是檢測器報告素養。不承諾分數，也不是規避指南。

更好的順序

  1. 保留收到的徽章/郵件；若可見任何數字，記下 attempt 或提交 ID。
  2. 禮貌向學校或 LMS 聯絡人索取同一次 attempt ID 的完整檢測匯出 PDF（或入口連結）。
  3. 打開匯出；對齊圖例、覆蓋範圍與 attempt ID，再點名片段。
  4. 然後再討論 flagged 連續正文——或準備面談短註。
  5. 若之後兩套工具不一致，把兩份完整匯出並排放。

為什麼禮貌索取很重要

印度與東南亞英授專案的導師通常打開誠信流程使用的同一入口 PDF。截圖百分比看不到覆蓋、圖例或哪些片段被標。索取完整匯出是流程素養，不是對抗——也能避免對著錯誤頁面改寫。

這不是什麼

  • 不保證下一張徽章會清零。
  • 不是建議在 PDF 出現前拒絕溝通——保持禮貌並遵守校規。
  • 若已正式啟動誠信程序，不能替代該程序。

HumanPen

HumanPen（humanpen.net）支援在你拿到完整匯出後，對照報告做文件級修訂。不保證下一個百分比。

記住

  • 徽章截圖 / 郵件 % ≠ 完整匯出。
  • 禮貌索取該 attempt ID 的 PDF（或入口檢視）。
  • 先對齊匯出，再爭論片段。
  • 誠實工具不承諾下一張乾淨卡片。
