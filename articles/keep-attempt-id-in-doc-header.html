Keep the attempt ID in the shared doc header

Charles Li / HumanPen

When the ID lives only in chat, the first scroll loses which export you opened.

This note continues detector-report literacy. It does not promise clearance. It asks you to keep the attempt ID in the shared doc header.

Why the header stays visible

Freeze a one-line header with attempt ID and export URL. Anyone joining late can match the file without hunting the thread.

Headers are logistics—not verdicts.

Four steps

  1. 1. Copy the attempt ID from the portal export.
  2. 2. Paste it into the shared doc header.
  3. 3. Add the export URL on the same line or the next.
  4. 4. Never sell a guaranteed pass.

HumanPen

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: ID in the header; badge is not a verdict.

Remember

  • Export URL beside it
  • Chat is backup only
