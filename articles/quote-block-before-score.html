Paste the flagged quote block before you argue about the score

Charles Li / HumanPen

Percentages travel well in chat. Flagged quote blocks do not—unless someone pastes them. The meeting stays fairer when the quote is visible first.

This note continues detector-report literacy. It does not promise clearance. It asks for the quote block before score talk.

Why the quote comes first

Include attempt ID, coverage, and legend notes beside the quote. If two tools disagree, paste both quotes with the same file stamp.

Rewrites come later; keep citations if you edit.

Four steps

  1. 1. Copy the flagged span text verbatim from the export.
  2. 2. Add attempt ID, coverage, and tool/version.
  3. 3. Only then discuss the headline percentage.
  4. 4. Plan edits as process—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: quote first; score second; disagreement stays paired to text.

Remember

  • Paste quote before score talk
  • Attempt ID + coverage beside it
  • Two tools → two dated quotes
  • HumanPen is workflow help, not a pass
