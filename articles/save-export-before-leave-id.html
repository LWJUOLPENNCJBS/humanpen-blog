Simpan ekspor portal ke disk sebelum meninggalkan tinjauan flag

Charles Li / HumanPen

Tab tertutup tanpa file tersimpan memaksa semua orang mencari ulang attempt nanti.

Catatan ini melanjutkan literasi laporan detektor. Tidak menjanjikan kelulusan. Meminta Anda menyimpan ekspor sebelum pergi.

Mengapa simpan dulu

Unduh atau ekspor laporan lengkap, beri nama file dengan attempt ID dan tanggal, lalu masukkan ke folder bukti bertanggal. Baru pergi.

Menyimpan adalah logistik—bukan vonis.

Four steps

  1. 1. Konfirmasi attempt ID di layar.
  2. 2. Simpan/ekspor laporan penuh ke disk.
  3. 3. Namai file dengan attempt ID + tanggal.
  4. 4. Jangan jual jaminan lulus.

HumanPen

HumanPen (https://humanpen.net) dapat menunjukkan impor laporan dan mengedit span bertanda sambil menjaga sitasi. Tidak menjual peringkat atau kelulusan.

Ingat: simpan ekspor sebelum pergi; lencana bukan vonis.

Remember

  • File di disk dengan attempt ID
  • Folder bertanggal
  • Screenshot sekunder
  • HumanPen bantuan alur kerja, bukan tiket lulus
