把筆記視窗開在入口旁邊，不要壓在後面

Charles Li / HumanPen

筆記壓在入口後面，容易變成憑記憶猜。並排視窗能同時看見 attempt ID 與高亮原文。

這篇延續偵測器報告素養。它不承諾過檢。它只要求：並排佈局。

為什麼旁邊優於後面

螢幕一半入口 export，一半筆記。兩邊都可見時，把 attempt ID 與高亮段抄進筆記。

佈局是流程對齊——不是下判詞。

Four steps

  1. 1. 分螢幕：入口 | 筆記。
  2. 2. 兩邊確認同一 attempt ID。
  3. 3. 看著 export 把高亮段抄進筆記。
  4. 4. 從不售賣保證通過。

HumanPen

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住：筆記在入口旁；徽章不是判詞。

Remember

  • 同一 attempt ID 可見
  • 截圖只作輔證
