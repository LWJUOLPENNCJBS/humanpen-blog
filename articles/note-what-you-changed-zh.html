改完 flagged 片段后，记下你改了什么

Charles Li / HumanPen

你已经改了 flagged 连续正文。再多做一小步：写一份带日期的短要点清单，记下改了什么、为什么。把这份笔记连同草稿痕迹带去办公室谈话。这是流程证据——不是认罪书。

这与长期人工修改痕迹、与改写前的 flagged 片段清单、与「改写循环不等于有罪」、与「diff 视图不等于认罪」、与相似度/AI 两段话脚本都不同。这里产物更窄：改后记下改了什么。

本文是检测器报告素养。不承诺分数，也不是规避指南。

轻量改后笔记

  1. 标注日期；记下 attempt / submission ID。
  2. 每条 bullet 对应一个改过的片段（短引文或位置）。
  3. 一行说明为什么：清晰度、引用匹配、作者身份说明等。
  4. 写明故意未动的部分（如参考文献）。
  5. 与草稿痕迹放在同一文件夹。

导师为什么要这个

印度与东南亚英授项目的导师常需要从报告高亮映射到你的修订。沉默或「我整篇重写了」只会让他们猜。带日期的改动清单展示作者过程，而不会把会面变成忏悔室。

这不是什么

  • 不保证下一张徽章会清零。
  • 不是强迫承认违纪。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持对照报告做文档级修订并保留引用与排版——之后你可以为办公室谈话记下改了什么。不保证下一个百分比。

记住

  • 改完后记下改了什么。
  • 带日期要点 + attempt ID + 草稿痕迹。
  • 流程证据 ≠ 认罪书。
  • 诚实工具不承诺下一张干净卡片。
