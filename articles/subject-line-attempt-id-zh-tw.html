討論 flag 前先把 attempt ID 寫進郵件主旨

Charles Li / HumanPen

「AI 87%」這類主旨傳得比它所指的 attempt 更遠。主旨裡沒有 ID，回覆就會爭論可能屬於另一份檔案的徽章。

這篇延續檢測器報告素養。它不承諾過檢。它只要求：討論前主旨裡先有 attempt ID。

為什麼先寫主旨

與入口 attempt 頁對齊。附上 export。工具名與覆蓋率寫在正文首行——不要埋在截圖下面。

郵件執行緒用來對齊流程——不是下判詞。

四步

  1. 1. 從入口或 export 頁首複製 attempt ID。
  2. 2. 主旨：課程代號 + attempt ID（百分比可選，絕不能單獨當標題）。
  3. 3. 正文首行：工具/版本 + 覆蓋率；附完整 export。
  4. 4. 需要時約短會一起讀——從不販售保證通過。

HumanPen 與記住
