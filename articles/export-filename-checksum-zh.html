用 attempt ID 命名 export 文件——能校验就再记 checksum

Charles Li / HumanPen

export 会被转发、改名，再和截图混在一起。文件名嵌入 attempt ID 与日期，不必打开每个附件也能读懂链条。

本文延续检测器报告素养。它不承诺过检。它要求在分数旁做好可留存的文件卫生。

为什么文件名重要

若可以，在准备表上记一短 checksum／哈希。两工具分歧时，保留两份已命名 export。

coverage 与图例说明仍要进案卷。

四步

  1. 1. 下载完整门户 export。
  2. 2. 改名：工具_attemptID_YYYYMMDD。
  3. 3. 可选：在准备表记 checksum。
  4. 4. 文件标好后再谈分——从不推销保证过检。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑 flagged span。它不卖排名或过检。

记住：先命名，后争论；两工具文件分开。

记住

  • 文件名带 attempt ID+日期
  • checksum 可选但有用
  • 两工具→两份命名 export
  • HumanPen 是流程工具，不是过检
