会议笔记顶部先写打分 attempt id

Charles Li / HumanPen

没有 attempt 抬头的好笔记很快会失效。谈第一个高亮之前，把打分 attempt id 与导出文件名写在便签第一行。几周后你仍知道谈话说的是哪份文件——不是含糊的「那篇论文」。

这与讨论前先问哪次 attempt、与先确认 attempt ID、与会后写三行 takeaways、与邮件主题写 attempt ID、与门户标签贴便签、与升级前文件夹日期戳、与开会带打印导出都不同。这里的素养动作很具体：谈任何高亮前，用 attempt id + 导出文件名给笔记加抬头。

本文是检测器报告素养。不承诺分数，也不是规避指南。

更好的顺序

  1. 打开空白笔记页；把 attempt id + 导出文件名写成标题行。
  2. 下面写会面日期与导师姓名。
  3. 然后再记片段、页码与那一个问题。
  4. 同一抬头复制进跟进日历邀请。
  5. 日后改写时，按该 id 打开笔记 + 匹配导出。

为什么抬头胜过记忆

印度与东南亚英授项目的导师常连续开多个短时段。周二未标注的笔记会与周三的 attempt 糊在一起。一行 attempt 抬头让 takeaways 仍挂在打分文件上。

这不是什么

  • 不保证下一张徽章会清零。
  • 若还没人点名，不能替代当面问打分的是哪一次。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持在笔记仍点明你们讨论过的 attempt 时，对照报告做文档级修订。不保证下一个百分比。

记住

  • 笔记顶部写 attempt id + 导出文件名。
  • 先抬头，再谈高亮。
  • 未标注笔记会糊掉谈的是哪份文件。
  • 诚实工具不承诺下一张干净卡片。
