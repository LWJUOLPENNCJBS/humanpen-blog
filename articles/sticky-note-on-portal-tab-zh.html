争徽章前先在门户标签贴一张便利贴

Charles Li / HumanPen

聊天比标签快。没打开 attempt 页就粘贴百分比，会让人臆造被打分的是哪份文件。

这篇延续检测器报告素养。它不承诺过检。它只要求：先在门户标签贴便利贴。

为什么先贴便利贴

写上 attempt ID、工具名与覆盖率——或直接改浏览器标签标题。让 export 下载链接一键可及。

聊天用来对齐流程——不是下判词。

四步

  1. 1. 打开门户 attempt 页；确认 ID 与邮件徽章一致。
  2. 2. 便利贴或标签标题：attempt ID + 覆盖率。
  3. 3. 下一条回复前先下载/附上完整 export。
  4. 4. 讨论流程下一步——从不售卖保证通过。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：先便利贴；徽章不是判词。

记住

  • 门户标签写 attempt ID
  • 争百分比前先看覆盖率
  • export 优先于截图
  • HumanPen 是流程助手，不是通行证
