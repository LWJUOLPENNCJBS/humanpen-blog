Peer review is not a detector score—and neither replaces the other

Charles Li / HumanPen

Mixing peer comments with a detector percentage collapses two jobs into one fight. Peer review asks whether the claim is supported. The badge asks which class a threshold prefers.

This note continues detector-report literacy. It does not promise clearance. It asks for two columns on the same sheet.

Why two columns

Bring attempt ID and coverage with the export. If tools disagree, keep both dated files. Keep citations if a rewrite follows.

Never treat weak peer feedback as proof of AI writing—or a low badge as a peer-review grade.

Four steps

  1. 1. Column A: peer comments on argument and sources.
  2. 2. Column B: detector export with attempt ID.
  3. 3. Note disagreements between tools as fairness data.
  4. 4. Plan next steps as process—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: two columns; two jobs; one fair meeting.

Remember

  • Peer review ≠ detector score
  • Export with attempt ID
  • Tool disagreement stays on file
  • HumanPen is workflow help, not a pass
