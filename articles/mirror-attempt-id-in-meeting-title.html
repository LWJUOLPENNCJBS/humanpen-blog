Mirror the attempt ID in the meeting title

Charles Li / HumanPen

A title that only says “flag meeting” hides which export everyone should open.

This note continues detector-report literacy. It does not promise clearance. It asks you to mirror the attempt ID in the meeting title.

Why the title field matters

Many calendars show only the title in week view. Paste a short ID suffix there so the right file is visible before anyone clicks.

Titles are logistics—not verdicts.

Four steps

  1. 1. Copy the attempt ID from the portal export.
  2. 2. Add a short ID suffix to the meeting title.
  3. 3. Keep the full ID and export URL in the invite body.
  4. 4. Never sell a guaranteed pass.

HumanPen

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: title mirrors ID; badge is not a verdict.

Remember

  • Full ID in the body
  • Export URL under it
