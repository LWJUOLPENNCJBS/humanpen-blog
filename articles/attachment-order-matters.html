Attachment order matters: syllabus, export, then screenshot

Charles Li / HumanPen

A badge screenshot at the top of a thread trains everyone to argue about a number. Put policy and the full export first, and the conversation starts with evidence.

This note continues detector-report literacy. It does not promise clearance. It only asks for a calmer attachment order.

Why order shapes the meeting

If two tools disagree, attach both dated exports with the same attempt ID. Keep coverage and legend notes visible.

Screenshots still help—just not as the opening exhibit.

Four steps

  1. 1. Attachment 1: syllabus AI clause (or note absence).
  2. 2. Attachment 2: full portal export(s) with attempt ID.
  3. 3. Attachment 3: optional badge screenshot labeled as secondary.
  4. 4. If rewrite follows, keep citations—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: order is part of fairness; screenshots are supporting, not the case.

Remember

  • Syllabus + export before screenshot
  • Same attempt ID on both exports
  • Screenshot is secondary
  • HumanPen is workflow help, not a pass
