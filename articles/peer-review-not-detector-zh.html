同伴互评不是检测分——两者不能互相替代

Charles Li / HumanPen

把同伴评语和检测百分比搅在一起，会把两件事打成一场架。互评问主张是否站得住；徽章问阈值偏好哪一类。

本文延续检测器报告素养。它不承诺过检。它要求同一张表上分两栏。

为什么要两栏

export 带上 attempt ID 与 coverage。若工具分歧，保留两份带日期文件。若随后改写，保留引用。

不要把弱互评当成 AI 写作证据——也不要把低徽章当成互评成绩。

四步

  1. 1. A 栏：同伴对论证与文献的评语。
  2. 2. B 栏：带 attempt ID 的检测 export。
  3. 3. 把工具分歧记为公正信号。
  4. 4. 下一步按流程——从不推销保证过检。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑 flagged span。它不卖排名或过检。

记住：两栏、两件事、一次公平约谈。

记住

  • 互评≠检测分
  • export 带 attempt ID
  • 工具分歧留档
  • HumanPen 是流程工具，不是过检
