办公室谈话带上与打分 attempt 同一份文件

Charles Li / HumanPen

若你打开的是报告后本地新改写，而导师门户仍显示产生打分 attempt ID 的旧文件，办公室谈话很容易跑偏：他们高亮的片段你「已经改过」；你显得在辩解；会面被浪费。

这与先确认 attempt ID、与一般的办公室版本核对、与保留人工修改痕迹、与邮件徽章 vs 门户、与索取完整导出、与先读大纲 AI 条款再拿分数对话、与改写前盖时间戳都不同。这里的规则很具体：带上与打分 attempt 匹配的同一份文件/PDF——不是笔记本上报告后的草稿。

本文是检测器报告素养。不承诺分数，也不是规避指南。

更好的顺序

  1. 在导出或门户卡片上确认 attempt ID。
  2. 下载或重新打开该 attempt 扫描的确切提交文件（LMS 版本／时间戳／文件名）。
  3. 把那份文件（连同完整导出）带到会面——与报告并排打开。
  4. 任何更新的改写放进单独文件夹；清楚标为报告后版本。
  5. 会面后再按校规决定是否重交修订稿。

为什么文件对不上会失败

印度与东南亚英授项目的导师打开的是你被打分的那次门户 attempt。若你屏幕上的段落不同，他们无法核对作者身份主张，也无法和你一起走 flagged 片段。笔记本上抛光过的草稿，替代不了那次谈话所需的打分文件。

这不是什么

  • 不保证下一张徽章会清零。
  • 不是建议隐瞒事后改过——可以说，并附短改动说明。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持在你基于正确的 attempt 文件时，对照报告做文档级修订。不保证下一个百分比。

记住

  • 与打分 attempt ID 同一份文件 → 会面。
  • 本地新改写 ≠ 导师看到的文件。
  • 导出 + 匹配提交并排。
  • 诚实工具不承诺下一张干净卡片。
