导入 Turnitin 报告，只改 flagged 片段

Charles Li / HumanPen

AI 百分比高，不等于整篇重写。更稳的顺序是：导入 Turnitin 或 iThenticate 的 AI 写作报告，只改写被标出的连续散文片段，引用、数字、公式与版式不动。这对应报告的建法——合格散文上的句级高亮——不是「绕过检测器」的许可证。

这与改写前先做 flagged 清单、与不要只改引言、与改写前先看图例、与先读覆盖再看百分比、与笔记逐字抄 span、以及已停用的会议 literacy 主题都不同。这里的产品素养动作很具体：报告进来 → 只动 flagged span → 冻住文档其余部分。

本文是报告阅读与文档修订素养。不承诺下一个分数，也不是规避或「undetectable」指南。

更好的顺序

  1. 打开完整导出（不是裁切徽章）。确认 attempt／Paper ID。
  2. 先读一遍图例与覆盖范围；记下排除项（如部分界面上的参考文献）。
  3. 把报告导入或对齐到你的 DOCX，使 flagged 片段可按序处理。
  4. 只改高亮的连续散文。冻住引文、引用域、数字、表格与页版式。
  5. 把改过的段落与原稿 diff；若用引用管理器域，在副本里刷新链接。

为什么整篇重写浪费一轮

国际学生常恐慌润色每一段。那可能打乱 Zotero／EndNote 域，却仍放过正文里密的 flagged 段。对准报告高亮，证据留着，你改的是模型实际打过分的散文。

这不是什么

  • 不保证下一个 AI 百分比会下降或清零。
  • 不是声称 HumanPen（或任何工具）undetectable，或能绕过 Turnitin。
  • 若课程已启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）面向对照检测报告的文档级修订：处理 flagged 片段，并尽量保留引用与版式。与「先读报告再动手」一类指南互补。不承诺下一个百分比。

记住

  • 先导入报告，不要盲改。
  • 先动 flagged 连续散文——不是整篇。
  • 冻住引用、数字、公式与版式。
  • 诚实工具不承诺下一张干净卡片。
