Mute the side chat before the span pass

Charles Li / HumanPen

A noisy side thread steals the minute you need to name each span.

This note continues detector-report literacy. It does not promise clearance. It asks you to mute the side chat before the span pass.

Why mute comes first

Mute notifications, open the export, then walk spans in order. Unmute only after the pass ends.

Mute is logistics—not a verdict.

Steps

  1. 1. Open the portal export.
  2. 2. Mute the side chat for the pass.
  3. 3. Name each span and page in order.
  4. 4. Never sell a guaranteed pass.

HumanPen
