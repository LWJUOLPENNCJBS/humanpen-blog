Put a sticky note on the portal tab before you argue the badge

Charles Li / HumanPen

Chat moves faster than tabs. A percentage pasted without the attempt page open invites people to invent which file was scored.

This note continues detector-report literacy. It does not promise clearance. It asks for a sticky note on the portal tab first.

Why the sticky note comes first

Write attempt ID, tool name, and coverage on the note—or rename the browser tab. Keep the export download link one click away.

Chat is for logistics—not for verdicts.

Four steps

  1. 1. Open the portal attempt page; confirm the ID matches the email badge.
  2. 2. Sticky note or tab title: attempt ID + coverage.
  3. 3. Download/attach full export before the next reply.
  4. 4. Discuss process next steps—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: sticky note first; badge is not a verdict.

Remember

  • Portal tab labeled with attempt ID
  • Coverage visible before chat debate
  • Export over screenshot
  • HumanPen is workflow help, not a pass
