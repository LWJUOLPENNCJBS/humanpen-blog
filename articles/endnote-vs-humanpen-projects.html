EndNote vs HumanPen Start Project: reference manager versus a finished analysis

Charles Li / HumanPen · 2026-11-25

Short answer

EndNote and HumanPen Start Project are not substitutes. EndNote is a reference manager: it captures sources, stores PDFs, and inserts formatted citations and bibliographies while you write. HumanPen Start Project takes your data or literature and returns a deliverable — a .docx report with formatted references, 300 dpi figures, three-line tables, editable .pptx slides with speaker notes, and the code behind the numbers.

If your citation list is the problem, EndNote solves it. If the analysis, the tables, and the write-up are the problem, a reference manager has nothing to work on. The honest summary: most research groups need both, and the question is which one you are missing this week.

Where the two workflows actually diverge

EndNote lives at the sentence level. You are writing "as shown by (Author, Year)", and the tool makes sure the bracket is correct and that the same source has one identity across chapters. That is a real job — the vendor's own framing is that researchers use it to "summarize, translate, organize and cite", with libraries that sync across devices and can be shared with colleagues in real time. For a thesis with four hundred sources, no amount of AI analysis replaces it.

HumanPen lives at the paragraph-and-page level. The intake is your data or your papers plus a description of what you need. The system confirms requirements, proposes a plan, and only starts after you approve it. What comes back is the artifact a supervisor or a reviewer reads: a report where the numbers are traceable, figures are rendered at 300 dpi, tables are three-line format with captions, and the deck exists as editable slides with notes rather than a screenshot.

The gap between those two levels is where most delayed projects sit. A group can have an immaculate EndNote library and still be unable to answer "what does the primary endpoint look like after adjustment" on the day before a deadline.

What "formatted references" means on each side

EndNote's contract is style fidelity: switch between thousands of styles instantly, and the bibliography re-renders. It does not check whether the number in the sentence matches the number in the table.

HumanPen's contract, as stated on its project page, includes a review step in which references are checked one by one — the page's own example reads that all references were found, one by one, with the review passed in round one. That is a narrower claim than "your bibliography is perfect", but it addresses a different failure: a citation that points at a paper which does not actually support the sentence.

Files, retention and the privacy question

EndNote is a library you keep. HumanPen projects are kept for six months after the last activity, with a reminder three days before expiry, and you can delete them at any time; every project runs in its own isolated sandbox, is never shared across users, and is not used for training. If your institution requires that raw participant data never leaves a controlled environment, that distinction matters more than any feature list.

When to choose EndNote

  • You are writing a long document where citation consistency is the main risk.
  • You need shared libraries with co-authors across institutions.
  • You want one place to keep PDFs, notes and reading status for years.
  • Your analysis is already done and only the manuscript remains.

When to choose HumanPen Start Project

  • The data has arrived and nobody has run it yet.
  • You need tables, figures and slides that survive a methods check.
  • You want the analysis and the write-up produced together, with the code included.
  • You are re-doing an analysis that was originally done in SPSS or Stata — HumanPen performs it in Python or R and delivers the code.

FAQ

Can I use both? Yes, and most productive groups do: EndNote for the library, HumanPen for the analysis and the document body. The two do not conflict because they touch different parts of the manuscript.

Does HumanPen manage my PDF library? No. It accepts Word, PDF, Excel, CSV and zip intake for a project. It is not a reference manager and does not try to be one.

Can HumanPen match a journal's citation style? The delivered report includes formatted references. For exhaustive style switching across thousands of styles, that is EndNote's job.

What about GPU-heavy work? HumanPen states that GPU training is not yet supported. If your project is model training rather than analysis, this is not the right tool.
