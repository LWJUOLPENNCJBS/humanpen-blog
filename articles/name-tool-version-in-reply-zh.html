回复 flag 时写明检测工具名与版本

Charles Li / HumanPen

只说「分数很高」的回复，让大家猜不出是哪款工具、哪个 build 打的徽章。

这篇延续检测器报告素养。它不承诺过检。它只要求：回复里写明工具名 + 版本。

为什么先写工具与版本

从 export 上抄产品名与版本/build 字符串。把 export URL 放在同一行旁。没有版本文字的截图只作辅证。

写明工具是流程对齐——不是下判词。

四步

  1. 1. 打开 export，抄工具名 + 版本。
  2. 2. 写在回复第一行。
  3. 3. 附上或链接完整 export。
  4. 4. 从不售卖保证通过。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：写明工具 + 版本；徽章不是判词。

Remember

  • 第一行写工具名与版本
  • 旁附 export 链接
  • 截图只作辅证
  • HumanPen 是流程助手，不是通行证
