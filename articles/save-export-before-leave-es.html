Una pestaña cerrada sin archivo guardado obliga a todos a volver a buscar el intento después.

Esta nota continúa la alfabetización de informes de detectores. No promete aprobación. Pide guardar el export antes de salir.

Por qué primero guardar

Descarga o exporta el informe completo, nombra el archivo con attempt ID y fecha, y déjalo en la carpeta de evidencia fechada. Luego sal.

Guardar es logística—no un veredicto.

Four steps

  1. 1. Confirma el attempt ID en pantalla.
  2. 2. Guarda/exporta el informe completo a disco.
  3. 3. Nombra el archivo con attempt ID + fecha.
  4. 4. Nunca vendas un aprobado garantizado.
