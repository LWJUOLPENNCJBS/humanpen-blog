把评分标准 PDF 与 export 绑到同一 attempt ID

Charles Li / HumanPen

没有对应 attempt ID 的评分标准，容易漂到另一篇作业的标准上。

这篇延续检测器报告素养。它不承诺过检。它只要求：用 attempt ID 绑定评分标准与 export。

为什么先绑定

把评分标准 PDF 放进以 attempt ID 命名的日期文件夹，或把同一 ID 写进文件名。与 export 并排打开。

绑定是流程对齐——不是下判词。

Four steps

  1. 1. 确认 export 上的 attempt ID。
  2. 2. 用该 ID 命名或标记评分标准 PDF。
  3. 3. 两者放进同一证据文件夹。
  4. 4. 从不售卖保证通过。

HumanPen

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：评分标准与 export 同一 attempt ID；徽章不是判词。

Remember

  • 评分标准用 attempt ID 绑定
  • 与 export 同文件夹
  • 截图只作辅证
  • HumanPen 是流程助手，不是通行证
