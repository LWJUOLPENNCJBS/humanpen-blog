争论任何高亮片段前先把报告图例读出声

Charles Li / HumanPen

一开口就说「这段黄的」跳过了图例。颜色在弄清色带前不是判决。办公室谈话时，先把报告图例读出声——每种颜色或置信色带是什么意思——再争论任何片段。「黄色」单独不是有罪标签。

这与改写前先看图例、与点名检测器版本、与回复里写工具版本、与核对置顶导出、与核对只开一个 PDF、与核对前关多余标签、与核对全屏导出都不同。这里的素养动作很具体：会上先把图例说出口，再谈片段。

本文是检测器报告素养。不承诺分数，也不是规避指南。

更好的顺序

  1. 打开打分导出；找到图例／图键／颜色说明。
  2. 与导师把每个色带读出声（例如浅色＝低置信，不是「抓到了」）。
  3. 在笔记 attempt id 下写一行图例释义。
  4. 再用共享含义走页码与片段。
  5. 若缺图例，先停——要完整导出再争论颜色。

为什么要读出声

印度与东南亚英授项目的导师与学生对同一色调常有不同含义。一起读图例锁定共享词汇，浅色带就不会被当成硬性有罪来争。

这不是什么

  • 不保证下一张徽章会清零。
  • 不是声称每个浅色片段都无事——只是颜色需要图键。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持在你与导师共享同一图例读法之后，对照报告做文档级修订。不保证下一个百分比。

记住

  • 争论片段前先把图例读出声。
  • 没有图键的「黄色」不是有罪标签。
  • 共享图例 → 共享含义。
  • 诚实工具不承诺下一张干净卡片。
