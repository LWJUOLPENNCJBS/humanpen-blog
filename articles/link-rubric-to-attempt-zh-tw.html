把評分標準 PDF 與 export 綁到同一 attempt ID

Charles Li / HumanPen

沒有對應 attempt ID 的評分標準，容易漂到另一篇作業的標準上。

這篇延續偵測器報告素養。它不承諾過檢。它只要求：用 attempt ID 綁定評分標準與 export。

為什麼先綁定

把評分標準 PDF 放進以 attempt ID 命名的日期資料夾，或把同一 ID 寫進檔名。與 export 並排打開。

綁定是流程對齊——不是下判詞。

Four steps

  1. 1. 確認 export 上的 attempt ID。
  2. 2. 用該 ID 命名或標記評分標準 PDF。
  3. 3. 兩者放進同一證據資料夾。
  4. 4. 從不售賣保證通過。

Remember

  • 評分標準用 attempt ID 綁定
  • 與 export 同資料夾
  • 截圖只作輔證
  • HumanPen 是流程助手，不是通行證
