Cocokkan attempt ID di tab email, portal, dan catatan

Charles Li / HumanPen

Tiga tab sering menampilkan tiga attempt berbeda. Mendebat ID campur membuang rapat.

Catatan ini melanjutkan literasi laporan detektor. Tidak menjanjikan kelulusan. Meminta Anda mencocokkan attempt ID dulu.

Mengapa pencocokan dulu

Baca ID di email flag, buka attempt yang sama di portal, dan tulis ID itu di atas catatan. Baru kemudian bahas span.

Mencocokkan ID adalah logistik—bukan vonis.

Four steps

  1. 1. Salin attempt ID dari email flag.
  2. 2. Konfirmasi ID yang sama di ekspor portal.
  3. 3. Tulis ID itu di tab catatan.
  4. 4. Jangan jual jaminan lulus.

HumanPen

HumanPen (https://humanpen.net) dapat menunjukkan impor laporan dan mengedit span bertanda sambil menjaga sitasi. Tidak menjual peringkat atau kelulusan.

Ingat: cocokkan attempt ID antar tab; lencana bukan vonis.

Remember

  • ID sama di email, portal, catatan
  • Bahas span setelah cocok
  • Screenshot sekunder
  • HumanPen bantuan alur kerja, bukan tiket lulus
