Open your notes window beside the portal—not behind it

Charles Li / HumanPen

Notes behind the portal become memory guesses. Side-by-side windows keep the attempt ID and span quotes visible.

This note continues detector-report literacy. It does not promise clearance. It asks for a side-by-side layout.

Why beside beats behind

Place the portal export on one half of the screen and notes on the other. Copy attempt ID and spans into notes while both stay visible.

Layout is logistics—not a verdict.

Four steps

  1. 1. Split the screen: portal | notes.
  2. 2. Confirm the same attempt ID in both.
  3. 3. Quote spans into notes while looking at the export.
  4. 4. Never sell a guaranteed pass.
