Don’t edit the live draft while screen-sharing—share the frozen export only

Charles Li / HumanPen

Screen-sharing the open .docx feels helpful. Typing a “quick fix” mid-share creates a new file state that no longer matches the scored attempt. Share only the frozen export (PDF/HTML) for that attempt; keep the editable draft closed or off-share.

This is distinct from freeze-draft-before-office-hours (lock before you join), from dont-rewrite-during-meeting, from match-word-count-to-export, from same-file-to-meeting, from office-hours-version-check, and from two-paragraph-office-hours. Here the literacy move is concrete: what you share on screen must stay the frozen export—no live edits mid-share.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Open the named attempt export (PDF/HTML) that matches the portal attempt id.
  2. Share that window or tab only—not the editor.
  3. Jot tutor notes in a separate pad off-share or in chat.
  4. If you must demo a tiny fix, stop sharing first and label it post-attempt scratch.
  5. Rewrite after takeaways on a scheduled follow-up—not live on the shared surface.

Why mid-share edits mislead

Tutors in India and Southeast Asia English-medium programs point at the shared object as the portal attempt. Edits mid-share make highlights look “wrong,” which gets misread as detector change. Usually the document simply drifted off the scored file while everyone watched.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a ban on scrolling or zooming the export—navigation yes, rewriting no.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report after the shared review, on the same frozen attempt. No guaranteed next percentage.

Remember

  • Share the frozen export only—never the live draft mid-share.
  • Mid-share edits ≠ “the detector changed.”
  • Stop sharing before any demo scratch.
  • Honest tools do not promise a clean next card.
