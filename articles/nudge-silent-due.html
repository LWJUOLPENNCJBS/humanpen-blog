After the first chase, send one short polite nudge—then wait

Charles Li / HumanPen

The first chase marks a silent due as unresolved. If there is still no ack, send one short polite nudge in the same thread with the due date restated—don’t pile on new asks; don’t escalate to email or a manager yet; one nudge, then wait. Use the same step for rewrite deadlines after a flag review.

This is distinct from no-silent-due (the first chase), from ack-due-in-chat, from confirm-due-with-owner, from due-beside-owner-in-notes, from end-with-owners-readback, from confirm-owner-before-leave, from schedule-followup-before-leave, and from capture-decision-in-chat. Here the literacy move is concrete: one restated-due nudge, then hold.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Confirm you already did the first chase (no-silent-due) with no ack.
  2. In the same thread: “Friendly nudge—still need your yes on due Fri EOD for the §3 rewrite. No new asks.”
  3. Restate only the due + owner + action—nothing else stacked on.
  4. Stop. Wait for the ack or a counter-date; don’t triple-ping.
  5. Escalate ownership or channel only after the nudge window, not mid-nudge.

Why one nudge beats a pile-on

Tutors in India and Southeast Asia English-medium programs ignore chat storms. A second message that only restates the rewrite deadline is readable; a stack of new asks looks like noise and gets muted. One nudge protects the export timeline without burning goodwill.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a second chase disguised as three new tasks.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report when rewrite deadlines were nudged once—not buried under a pile of asks. No guaranteed next percentage.

Remember

  • After the first chase: one short polite nudge.
  • Restate the due—don’t pile on new asks.
  • Don’t escalate to email/manager yet; nudge, then wait.
  • Honest tools do not promise a clean next card.
