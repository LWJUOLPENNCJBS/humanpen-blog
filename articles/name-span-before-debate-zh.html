先点名高亮段，再争论分数

Charles Li / HumanPen

没有段落的百分比，会把会议变成猜谜。

本条延续检测器报告素养。它不承诺过检。它只要求先点名高亮段，再争论分数。

为什么先点段

先读 attempt ID，再说你指哪一段高亮。然后才谈怎么改。

Naming spans is logistics—not a verdict.

Steps

  1. 1. 从 export 复制 attempt ID。
  2. 2. 指出高亮段与页码。
  3. 3. 争论改法——不要只盯徽章。
  4. 4. 从不售卖保证过检。

HumanPen

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: name the span first; badge is not a verdict.
