Name the export file with attempt ID—then checksum if you can

Charles Li / HumanPen

Exports get forwarded, renamed, and mixed with screenshots. A filename that embeds attempt ID and date keeps the chain readable without opening every attachment.

This note continues detector-report literacy. It does not promise clearance. It asks for durable file hygiene beside the score.

Why the filename matters

If you can, jot a short checksum or hash on the prep sheet. When two tools disagree, keep both named exports.

Coverage and legend notes still belong in the packet.

Four steps

  1. 1. Download the full portal export.
  2. 2. Rename: tool_attemptID_YYYYMMDD.
  3. 3. Optional: record a checksum on the prep sheet.
  4. 4. Discuss scores only after files are labeled—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: name first; argue second; keep both tool files distinct.

Remember

  • Filename carries attempt ID + date
  • Checksum optional but useful
  • Two tools → two named exports
  • HumanPen is workflow help, not a pass
