讨论标记时写清检测产品名与版本

Charles Li / HumanPen

只说「AI检测器标了我」几乎永远不够。导师需要产品名以及版本、构建号或报告/attempt 日期。缺了这些，你可能在争另一套工具、旧的 LMS 集成，或一次图例已变的重跑。

这与「一个检测器不够」、与确认 attempt ID、与索取完整导出、与两份导出并排、与评分标准与导出并排、与改写前盖时间戳、与改写前对齐图例都不同。这里的素养动作很具体：争论片段前，先写清产品名 + 版本/日期。

本文是检测器报告素养。不承诺分数，也不是规避指南。

更好的顺序

  1. 按门户或导出页眉原样抄下产品名。
  2. 记下版本、构建、模型标签，或至少报告日期／attempt 时间戳。
  3. 把 attempt ID 与这一对信息放在一起，避免与重跑混在一起。
  4. 邮件或办公室谈话先写产品 + 版本/日期，再写 % 与片段。
  5. 若出现第二套工具，分别点名——不要并成一句「AI检测」。

为什么笼统说会谈空

印度与东南亚英授项目的学校可能换供应商、启用 LMS 插件或刷新报告模板。没有产品/版本的截图百分比，对不上政策、培训或先例。写清构建是流程清晰，不是迂腐。

这不是什么

  • 不保证下一张徽章会清零。
  • 不是建议换检测器直到看起来更友好。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持在产品与 attempt 身份清楚后，对照具名报告做文档级修订。不保证下一个百分比。

记住

  • 产品名 + 版本/日期——不要只说「AI检测器」。
  • 与 attempt ID 成对记录。
  • 两套工具 → 两行具名。
  • 诚实工具不承诺下一张干净卡片。
