回覆 flag 郵件前先收藏入口 export URL

Charles Li / HumanPen

Flag 郵件常只附裁切截圖。只憑圖片回覆，會丟掉 attempt ID 與即時 export 連結。

這篇延續偵測器報告素養。它不承諾過檢。它只要求：回覆前先收藏入口 export URL。

為什麼先收藏

打開入口、打開被打分的 attempt，複製 export URL，用 attempt ID 命名瀏覽器書籤。回覆附上該 URL——不要用手機拍徽章。

書籤用來對齊流程——不是下判詞。

四步

  1. 1. 在 flag 郵件旁打開入口。
  2. 2. 打開郵件點名的那一次 attempt。
  3. 3. 收藏 export URL（用 attempt ID 命名）。
  4. 4. 回覆附上該書籤——從不售賣保證通過。

HumanPen 與記住

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住：先收藏 export URL；徽章不是判詞。

Remember

  • 書籤含 attempt ID
  • 回覆附即時 export URL
  • 截圖只作輔證
  • HumanPen 是流程助手，不是通行證
