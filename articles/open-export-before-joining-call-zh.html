进 flag 通话前先打开 export

Charles Li / HumanPen

先点加入再找文件，会烧掉会议里仅有的安静一分钟。

本条延续检测器报告素养。它不承诺过检。它只要求进房前先打开 export。

为什么文件先于摄像头

先在屏幕上核对 attempt ID 与页数，再点加入。通话从邀请里点名的同一份材料开始。

准备是后勤，不是裁决。

四步

  1. 1. 用邀请里的 URL 打开门户 export。
  2. 2. 对自己读一遍 attempt ID。
  3. 3. 保持该窗口置顶再加入通话。
  4. 4. 从不售卖保证过检。

HumanPen
