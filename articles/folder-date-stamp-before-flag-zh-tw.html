升級檢測 flag 前先給證據資料夾打上日期戳

Charles Li / HumanPen

截圖堆在桌面卻沒有家。沒有日期的證據堆，很難證明大家討論的是哪一次 attempt。

這篇延續檢測器報告素養。它不承諾過檢。它只要求：升級前先給資料夾打日期戳。

為什麼先打日期戳

資料夾命名：YYYY-MM-DD + attempt ID。任何轉發前先放進完整 export。若要開會，把大綱條款 PDF 放旁邊。

資料夾用來對齊流程——不是下判詞。

四步

  1. 1. 新建資料夾：日期 + attempt ID。
  2. 2. 把完整 export（及工具/版本備註）放進去。
  3. 3. 開會需要時再加大綱/評分標準。
  4. 4. 升級時附上該資料夾連結——從不販售保證通過。

HumanPen 與記住

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住：先日期戳；徽章不是判詞。

記住

  • 資料夾含日期與 attempt ID
  • 升級前先放 export
  • 截圖只作輔證
  • HumanPen 是流程助手，不是通行證
