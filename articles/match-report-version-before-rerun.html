Match the report version before you rerun

Charles Li / HumanPen

Re-checking against a newer detector build can move highlights even when your DOCX did not change.

This note is detector-report literacy for HumanPen document polish. It does not promise clearance or an undetectable rewrite. It asks you to match report version before a rerun.

Same file, different highlights

Note the report timestamp and product version. Import that export into HumanPen; rewrite flagged spans only; freeze citations, numbers, and layout.

Badge is not a verdict—compare like with like.

Steps

  1. Record detector name and report timestamp.
  2. Import the matching export into HumanPen.
  3. Rewrite flagged spans only; keep claim strength.
  4. Never treat a new score as a guaranteed pass.

HumanPen

HumanPen (https://humanpen.net) helps import a detection report and rewrite flagged spans while layout and citations stay intact. It does not sell rankings or clearance.

Remember

  • Version matched before rerun
  • Flagged prose only
  • Citations and layout frozen
  • HumanPen is polish help, not a pass
