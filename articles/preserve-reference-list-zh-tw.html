改寫 flagged 段落後，參考文獻表應原樣回來

Charles Li / HumanPen

在 humanpen.net，當你改寫被標出的連續散文後，參考文獻／書目表應原樣回來——順序、標點、DOI 與條目正文。HumanPen 不是整篇洗稿，不會重排或「潤色」文末引用。

這補充 freeze-citations-numbers-formulas（文內引用、數字、公式凍結）與 tables-captions-stay-intact（表格與題註保留）。它不同於 keep-citations-through-loop、headings-styles-come-back / docx-layout-stays-intact、dont-wash-whole-document / only-flagged-continuous-prose / leave-unflagged-prose-alone、recheck-after-detector-update。本文點名參考文獻表保真：潤色 flagged 散文 → References／Works Cited／Bibliography 預設不動，除非該塊本身就是被標出的連續散文。

不承諾下一次 AI%。不教「繞過檢測／undetectable」。學校政策仍決定是否結案。

為什麼參考文獻表必須原樣

  1. 參考條目是結構化資料（作者、年份、題名、刊物、DOI）——洗它們容易弄斷引用並製造 Similarity 雜訊。
  2. 整篇「humanizer」常重排、改寫或丟掉條目；這正是本文拒絕的失敗模式。
  3. 文內引用記號與文末列表必須對齊；只改列表（或只改正文卻不核對連結）都會拆散這對關係。
  4. 檢測器與 Similarity 面板對待參考文獻塊往往不同於連續散文——不要「優化」列表指望更低 AI%。
  5. 誠實的文件級工具預設凍結列表，只動報告真正標出的連續散文。

可執行流程（對齊 HumanPen）

  1. 把 Turnitin／iThenticate AI 寫作報告匯入 HumanPen。
  2. 確認哪些跨度是 flagged 連續散文——以及 References 塊本身是否被標出（通常不是）。
  3. 只改寫 flagged 連續散文；凍結文內引用、數字、公式、術語、表格、題註與參考文獻表。
  4. 匯出後抽查：條目數、順序、DOI／URL，以及文內鍵是否仍匹配列表。
  5. 下一輪重新匯入新報告；若有免費輪，仍只作用於首頁口徑下仍被標出的散文——不是去重排 References。

這不是什麼

  • 不保證下一次 AI% 或 Similarity% 會下降或過學校政策線。
  • 不是允許改寫、翻譯或「潤色」書目表讓它看起來更不像機器。
  • 不是「undetectable」、繞過，或隱藏署名的建議。
  • 不能替代文內記號的 freeze-citations-numbers-formulas，或圖表的 tables-captions-stay-intact。

HumanPen 適合什麼

HumanPen（humanpen.net）是文件級 AI 改寫工具：匯入報告、改 flagged 連續散文、盡量保引用、參考文獻表與版式、按改寫字計費，並在首頁口徑下對剩餘 flagged 提供免費輪次。保住參考文獻表是這種誠實的一部分——不是可選項。
