邮件徽章 vs 门户导出：先打开报告再争论

Charles Li / HumanPen

LMS 邮件或通知卡片常显示一个紧凑的 AI writing 百分比。打开同一 attempt 的门户导出时，这个数字可能对不上。请带着可见 attempt ID 的门户报告 PDF 争论——不要只凭邮件徽章。

这与 LMS vs Messenger 截图、与门户徽章对齐 PDF 覆盖、与「截图≠案卷」、与两份工具导出并排、与办公室谈话两段话脚本都不同。这里更窄：通知卡片 vs 门户导出。

本文是检测器报告素养。不承诺分数，也不是规避指南。

为什么卡片会对不上

  • 邮件摘要可能滞后于重跑或后一次 attempt。
  • 卡片常只给摘要色带，没有完整连续正文高亮。
  • 教师邮件与学生门户视图可能按不同时钟刷新。
  • 没有 attempt ID，你可能在比两份不同提交。

印度与东南亚英授项目的学生常先凭邮件截图升级冲突，却还没打开导师实际使用的门户 PDF。

改为这样做

  1. 打开门户提交行；抄下 attempt / submission ID。
  2. 下载该 ID 对应的完整报告 PDF（或官方导出）。
  3. 仅在 ID 一致后，再把邮件 % 与门户导出比较。
  4. 办公室谈话带 PDF——不要只带邮件。

这不是什么

  • 不保证门户数字会更低。
  • 不是建议忽略学校发来的邮件。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持对照完整报告处理文档并保留引用与排版——适合在门户导出成为事实源之后使用。不保证下一个百分比。

记住

  • 邮件徽章 ≠ 最终门户导出。
  • 争论卡片前先有 attempt ID + PDF。
  • 滞后与摘要视图解释许多不一致。
  • 诚实工具不承诺下一张干净卡片。
