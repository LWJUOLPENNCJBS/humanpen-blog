把 attempt ID 留在共享文件頁首

Charles Li / HumanPen

ID 只留在聊天裡時，一捲動就不知道開啟的是哪份 export。

本條延續檢測器報告素養。它不承諾過檢。它只要求把 attempt ID 留在共享文件頁首。

為什麼頁首要一直可見

凍一行頁首：attempt ID + export URL。遲到的人也能對齊檔案，不必翻整段執行緒。

頁首是後勤，不是裁決。

四步

  1. 1. 從入口 export 複製 attempt ID。
  2. 2. 貼進共享文件頁首。
  3. 3. 同一行或下一行附上 export URL。
  4. 4. 從不售賣保證過檢。

HumanPen

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住：ID 在頁首；徽章不是裁決。

記住

  • 頁首含 ID
  • 旁附 export URL
  • 聊天只作備份
  • HumanPen 是流程助手，不是通行證
