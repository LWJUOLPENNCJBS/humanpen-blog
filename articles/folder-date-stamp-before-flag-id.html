Cap tanggal folder sebelum menaikkan flag detektor

Charles Li / HumanPen

Screenshot menumpuk tanpa rumah. Tumpukan tanpa tanggal sulit membuktikan attempt mana yang dibahas.

Catatan ini melanjutkan literasi laporan detektor. Tidak menjanjikan kelulusan. Hanya meminta cap tanggal folder sebelum eskalasi.

Mengapa cap folder dulu

Nama folder: YYYY-MM-DD + attempt ID. Masukkan export penuh sebelum forward. Simpan PDF klausul silabus di samping jika akan bertemu.

Folder untuk logistik—bukan putusan.

Empat langkah

  1. 1. Buat folder: tanggal + attempt ID.
  2. 2. Simpan export penuh (plus catatan alat/versi) di dalamnya.
  3. 3. Tambah silabus/rubrik hanya jika perlu untuk pertemuan.
  4. 4. Eskalasi dengan tautan folder itu—jangan jual jaminan lolos.

HumanPen dan ingat

HumanPen (https://humanpen.net) dapat menggambarkan impor laporan dan mengedit rentang ditandai dengan sitasi tetap. Tidak menjual peringkat atau kelulusan.

Ingat: cap tanggal folder; lencana bukan putusan.
