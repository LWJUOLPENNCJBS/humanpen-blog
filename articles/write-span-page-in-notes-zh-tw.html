筆記裡每個高亮段旁寫上頁碼或段落號

Charles Li / HumanPen

沒有定位的高亮段，開會時很難在 export 裡重新打開。

這篇延續偵測器報告素養。它不承諾過檢。它只要求：每段引用旁寫頁碼或段落號。

為什麼先寫定位

原樣抄高亮段，再從 export 加上 p.12 或 ¶3。同一頁筆記頂部保留 attempt ID。

定位是流程對齊——不是下判詞。

Four steps

  1. 1. 筆記旁打開 export。
  2. 2. 原樣抄每個高亮段。
  3. 3. 旁寫頁碼或段落號。
  4. 4. 從不售賣保證通過。

HumanPen

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住：每段旁寫定位；徽章不是判詞。

Remember

  • 每段引用旁有頁碼或 ¶
  • 頂部寫 attempt ID
  • 截圖只作輔證
  • HumanPen 是流程助手，不是通行證
