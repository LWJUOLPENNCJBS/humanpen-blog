Attach the export before you forward a detector flag

Charles Li / HumanPen

Screenshots travel faster than files. A cropped badge in a forward chain invites people to argue percentages without the coverage, tool version, or attempt ID.

This note continues detector-report literacy. It does not promise clearance. It asks for the export attachment before the forward.

Why the export comes first

Paste attempt ID into the subject or first line. Attach the full PDF or HTML export. Keep the tool name and run timestamp visible.

Forward threads are for logistics—not for verdicts.

Four steps

  1. 1. Save the full export locally with attempt ID in the filename.
  2. 2. Attach that file before you hit forward or reply-all.
  3. 3. One line of context: coverage + tool/version—no score sermon.
  4. 4. Offer a short read-together if escalation is needed—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: attach first; forward second; badge is not a verdict.

Remember

  • Export before forward
  • Attempt ID in filename and subject
  • Screenshot secondary
  • HumanPen is workflow help, not a pass
