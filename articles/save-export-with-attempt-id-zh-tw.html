儲存檢測匯出時檔名立刻帶上 attempt ID

Charles Li / HumanPen

入口下載常叫 Report.pdf 或 Download.pdf。重交兩次後，桌面三個同名檔，面談打開錯的那份。辦法無聊但可靠：檔案一落地就改名，寫上 attempt ID，至少寫上報告日期。

這與先確認 attempt ID、與索取完整匯出、與裁切藏掉 attempt ID、與會面帶同一檔、與改寫前蓋時間戳、與兩份匯出並排都不同。這裡的素養動作很具體：進堆之前，檔名先帶上 attempt ID（或日期）。

本文是檢測器報告素養。不承諾分數，也不是規避指南。

更好的順序

  1. 下載你關心的那次 attempt 的完整匯出。
  2. 從首頁或入口卡片讀出 attempt ID（若可見，還有產品/版本）。
  3. 立刻改名，例如 課程_AI匯出_attempt-48219_2026-10-14.pdf。
  4. 與帶同一 ID 記號的匹配提交檔放在一起。
  5. 會上打開這對具名檔——不要從下載資料夾隨便點一個 Report.pdf。

為什麼通用檔名會失敗

印度與東南亞英授專案的導師依據的是某一次 attempt。若你螢幕上是另一份匯出，片段與百分比會對不上他們的入口。清晰檔名是流程衛生：避免爭錯 PDF，也避免重跑混在一起。

這不是什麼

  • 不保證下一張徽章會清零。
  • 不是建議改 PDF 內容——只改檔名與歸檔。
  • 若已正式啟動誠信程序，不能替代該程序。

HumanPen

HumanPen（humanpen.net）支援在你基於正確具名的 attempt 匯出時，對照報告做文件級修訂。不保證下一個百分比。
