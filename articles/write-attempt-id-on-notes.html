Write the scored attempt id at the top of your meeting notes

Charles Li / HumanPen

Good notes without an attempt header go stale fast. Before the first highlight, put the scored attempt id and export filename on line one of your pad. Weeks later you will know which file the conversation was about—not a vague “that paper.”

This is distinct from ask-which-attempt-before-discuss (ask aloud first), from confirm-attempt-id-first, from write-meeting-takeaways (three lines after), from subject-line-attempt-id, from sticky-note-on-portal-tab, from folder-date-stamp-before-flag, and from bring-printed-export-to-meeting. Here the literacy move is concrete: header the notes with attempt id + export name before any highlight talk.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Open a blank notes page; write attempt id + export filename as the title line.
  2. Add meeting date and tutor name under it.
  3. Only then record spans, page numbers, and your one question.
  4. Copy the same header into the follow-up calendar invite.
  5. When you rewrite later, open notes + matching export by that id.

Why a header beats memory

Tutors in India and Southeast Asia English-medium programs often run several short slots back-to-back. Unlabeled notes from Tuesday blur into Wednesday’s attempt. A one-line attempt header keeps takeaways attached to the scored file.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a substitute for asking which attempt was scored if nobody has named it yet.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report when your notes still name the attempt you discussed. No guaranteed next percentage.

Remember

  • Write attempt id + export filename at the top of notes.
  • Header before highlight talk.
  • Unlabeled notes blur which file was discussed.
  • Honest tools do not promise a clean next card.
