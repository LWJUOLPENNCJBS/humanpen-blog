Bring the lab notebook before you bring the detector score

Charles Li / HumanPen

Detectors summarize surface cues. A lab notebook (or process log) shows what the student actually did: when drafts moved, which citations stayed, which spans changed.

This note continues detector-report literacy. It does not promise clearance. It asks for process evidence beside the export.

Why the notebook comes first

Pair the notebook with attempt ID and coverage from the portal. If two tools disagree, keep both dated exports.

Screenshots of badges come last.

Four steps

  1. 1. Collect dated draft notes or lab entries.
  2. 2. Attach full export(s) with attempt ID.
  3. 3. Only then discuss the headline score.
  4. 4. If rewrite follows, keep citations—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: notebook first; score second; disagreement stays on file.

Remember

  • Process notes before score talk
  • Attempt ID + coverage with export
  • Badge screenshot is last
  • HumanPen is workflow help, not a pass
