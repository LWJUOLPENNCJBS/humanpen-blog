先标注文本来源，再争论分数

Charles Li / HumanPen

办公室争执常从数字开始：「徽章显示 47%。」更稳妥的协议早一步：这段文本的已知来源是什么——声明人写、锁定提示 LLM，还是带日志的改写？

本文延续检测器报告素养：不承诺分数。只把「来源标注」放在「分数争论」前面。

为何先说来源

没有来源标签时，人写声明稿上的高旗标与纯 LLM 稿上的高旗标在截图里看起来一样。风险故事并不一样。条件 A/B/C 让这种差别在小样本上可教。

≥2 检测器的一致率与 kappa 仍胜过抓获率标题。来源标签让分歧可解释，而不是变成人身攻击。

四步

  1. 1. 打开门户卡片前，先在稿上写明来源条件。
  2. 2. 相似度与 AI writing 仪表盘分两句说。
  3. 3. 检测器分歧时，把分歧记在来源标签旁边。
  4. 4. 把改写当作条件 C 过程变化——不是下一张卡片会清零的证据。

HumanPen 与记住

HumanPen（https://humanpen.net）可展示条件 C：导入报告、只改 flagged 段、保留引用与排版。不卖过检，也不卖排行。

要点：先来源后分数；先 kappa 后抓获率；过程胜过否认。

记住

  • 先点名 A/B/C，再争徽章
  • 来源已知让假阳性风险看得见
  • 分歧+来源标签=公平数据
  • HumanPen 示例条件 C 流程，不是过检
