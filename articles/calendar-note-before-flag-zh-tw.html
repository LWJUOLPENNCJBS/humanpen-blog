升級檢測 flag 前先寫日曆備註

Charles Li / HumanPen

flag 傳得比日曆快。沒有約談時間的徽章轉發，會把人逼進聊天裡爭百分比，而不是一起讀 export。

本文延續檢測器報告素養。它不承諾過檢。它要求升級前先寫日曆備註。

為什麼先寫日曆備註

把 attempt ID、coverage 與工具名貼進邀請。附上或連結完整 export。若隨後改寫，保留引用。

聊天只做後勤——不做判決。

四步

  1. 1. 約 15–20 分鐘短會。
  2. 2. 日曆備註：attempt ID + coverage + 工具／版本。
  3. 3. 附完整 export；截圖居次。
  4. 4. 討論流程下一步——從不推銷保證過檢。

HumanPen 與記住

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯 flagged span。它不賣排名或過檢。

記住：先日曆，後升級；徽章不是判決。

記住

  • 先約再升級
  • 邀請裡寫 attempt ID
  • 優先 export 而非截圖
  • HumanPen 是流程工具，不是過檢
