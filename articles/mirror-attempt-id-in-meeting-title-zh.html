把 attempt ID 同步进会议标题

Charles Li / HumanPen

标题只写「flag 会议」时，大家仍不知道要打开哪份 export。

本条延续检测器报告素养。它不承诺过检。它只要求把 attempt ID 同步进会议标题。

为什么标题字段重要

很多日历在周视图只显示标题。把短 ID 后缀贴进去，点开前就能对齐文件。

标题是后勤，不是裁决。

四步

  1. 1. 从门户 export 复制 attempt ID。
  2. 2. 把短 ID 后缀写进会议标题。
  3. 3. 完整 ID 与 export URL 仍放在邀请正文。
  4. 4. 从不售卖保证过检。

HumanPen

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：标题同步 ID；徽章不是裁决。

记住

  • 标题含短 ID
  • 正文含完整 ID
  • 下附 export URL
  • HumanPen 是流程助手，不是通行证
