Tres pestañas a menudo muestran tres intentos distintos. Debatir IDs mezclados pierde la reunión.

Por qué primero el emparejamiento

Lee el ID en el correo del flag, abre ese intento exacto en el portal y escribe el mismo ID arriba de tus notas. Solo entonces discute tramos.

Emparejar IDs es logística—no un veredicto.

Four steps

  2. 2. Confirma el mismo ID en el export del portal.
  3. 3. Escríbelo en la pestaña de notas.
  4. 4. Nunca vendas un aprobado garantizado.
