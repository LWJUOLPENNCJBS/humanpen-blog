离开 flag 核对前先把门户 export 存到本地

Charles Li / HumanPen

关掉标签却没存文件，之后大家又要重新找那次 attempt。

这篇延续检测器报告素养。它不承诺过检。它只要求：离开前先存 export。

为什么先存

下载或导出完整报告，用 attempt ID 与日期命名，放进已打日期戳的证据文件夹。然后再离开。

存盘是流程对齐——不是下判词。

Four steps

  1. 1. 确认屏幕上的 attempt ID。
  2. 2. 把完整报告存到本地。
  3. 3. 文件名含 attempt ID + 日期。
  4. 4. 从不售卖保证通过。

HumanPen

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：离开前先存 export；徽章不是判词。

Remember

  • 本地文件含 attempt ID
  • 放进日期文件夹
  • 截图只作辅证
  • HumanPen 是流程助手，不是通行证
