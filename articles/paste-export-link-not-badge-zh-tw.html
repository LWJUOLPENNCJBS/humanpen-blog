在 flag 執行緒貼 export 連結，不要只貼徽章圖

Charles Li / HumanPen

徽章 PNG 只顯示一個數字，藏起 attempt ID、工具版本與高亮列表。

這篇延續偵測器報告素養。它不承諾過檢。它只要求：貼上即時 export URL。

為什麼連結優於徽章圖

複製被打分 attempt 的入口 export URL。把該 URL 貼進執行緒。截圖只作輔證附件。

連結用來對齊流程——不是下判詞。

Four steps

  1. 1. 在入口打開被打分的 attempt。
  2. 2. 複製 export URL。
  3. 3. 把 URL 貼進 flag 執行緒。
  4. 4. 從不售賣保證通過。

HumanPen

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住：貼 export 連結；徽章不是判詞。

Remember

  • 執行緒裡放 export URL
  • 徽章圖只作輔證
  • 透過連結可見 attempt ID
  • HumanPen 是流程助手，不是通行證
