Keep DOCX layout intact while you rewrite flagged spans

Charles Li / HumanPen

Pasting the whole paper into a chat box often strips headings, captions, and citation fields—even when only a few AI-flagged paragraphs needed work.

This note is about HumanPen document polish and detector-report literacy. It does not promise clearance or an undetectable rewrite. It asks you to keep DOCX layout intact while editing flagged prose.

Why layout is part of the evidence

Styles and tables carry structure reviewers trust. Freeze citations, numbers, and formulas; rewrite flagged prose; export so headings and spacing come back.

Layout preservation is logistics for evidence—not a verdict.

Steps

  1. Import the Turnitin / iThenticate-style export (or select flagged spans).
  2. Rewrite only those passages in HumanPen.
  3. Keep citations, numbers, formulas, and DOCX styles intact.
  4. Never sell a guaranteed pass.

HumanPen

HumanPen (https://humanpen.net) is built for importing a detection report and rewriting flagged spans while DOCX layout, citations, and formulas stay intact. It does not sell rankings or clearance.

Remember

  • DOCX layout preserved
  • Flagged prose only
  • Citations and formulas frozen
  • HumanPen is polish help, not a pass
