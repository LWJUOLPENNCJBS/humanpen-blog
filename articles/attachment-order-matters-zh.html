附件顺序很重要：先大纲与 export，再徽章截图

Charles Li / HumanPen

把徽章截图放在邮件最前，会逼所有人先争数字。先放政策与完整 export，对话才从证据开始。

本文延续检测器报告素养。它不承诺过检。它只要求更冷静的附件顺序。

为什么顺序会塑造约谈

若两工具分歧，附上同一 attempt ID 的两份带日期 export，并让 coverage 与图例可见。

截图仍有用——只是不要当开场证物。

四步

  1. 1. 附件1：大纲 AI 条款（或注明缺失）。
  2. 2. 附件2：带 attempt ID 的完整门户 export。
  3. 3. 附件3：可选徽章截图，标为次要。
  4. 4. 若随后改写，保留引用——从不推销保证过检。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑 flagged span。它不卖排名或过检。

记住：顺序也是公正的一部分；截图是辅助，不是案卷本身。

记住

  • 先大纲+export 再截图
  • 两份 export 同一 attempt ID
  • 截图居次
