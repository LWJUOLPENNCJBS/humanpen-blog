Put the attempt ID in the email subject before you discuss a flag

Charles Li / HumanPen

Subjects like “AI 87%” travel farther than the attempt they refer to. Without an ID in the subject, replies argue a badge that may belong to another file.

This note continues detector-report literacy. It does not promise clearance. It asks for attempt ID in the subject before the discussion.

Why the subject comes first

Match the portal attempt page. Attach the export. Keep tool name and coverage in the first body line—not buried under screenshots.

Email threads are for logistics—not for verdicts.

Four steps

  1. 1. Copy attempt ID from the portal or export header.
  2. 2. Subject: course code + attempt ID (percentage optional, never alone).
  3. 3. Body line 1: tool/version + coverage; attach full export.
  4. 4. Ask for a short read-together if needed—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: ID in the subject; badge is not a verdict.

Remember

  • Attempt ID in the subject
  • Export attached
  • Percentage never alone in the title
  • HumanPen is workflow help, not a pass
