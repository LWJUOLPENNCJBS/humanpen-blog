離開 flag 核對前先把入口 export 存到本機

Charles Li / HumanPen

關掉分頁卻沒存檔，之後大家又要重新找那次 attempt。

這篇延續偵測器報告素養。它不承諾過檢。它只要求：離開前先存 export。

為什麼先存

下載或匯出完整報告，用 attempt ID 與日期命名，放進已打日期戳的證據資料夾。然後再離開。

存檔是流程對齊——不是下判詞。

Four steps

  1. 1. 確認螢幕上的 attempt ID。
  2. 2. 把完整報告存到本機。
  3. 3. 檔名含 attempt ID + 日期。
  4. 4. 從不售賣保證通過。

HumanPen

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住：離開前先存 export；徽章不是判詞。

Remember

  • 本機檔案含 attempt ID
  • 放進日期資料夾
  • 截圖只作輔證
  • HumanPen 是流程助手，不是通行證
