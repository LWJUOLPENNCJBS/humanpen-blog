Import the Turnitin report, rewrite flagged passages only

Charles Li / HumanPen

A high AI percentage is not a cue to rewrite the whole file. A safer order is: import the Turnitin or iThenticate AI writing report, revise only the flagged continuous-prose spans, and leave citations, numbers, formulas, and layout alone. That matches how the report is built—sentence-level highlights on qualifying prose—not a license to “bypass” a detector.

This is distinct from flagged-span-checklist (list before you edit), from dont-rewrite-only-intro, from legend-before-rewrite, from coverage-before-percent, from quote-span-verbatim-in-notes, and from meeting-literacy themes (now retired for this channel). Here the product literacy move is concrete: report in → flagged spans only → freeze the rest of the document.

This note is report-reading and document-revision literacy. It does not promise any next score, and it is not a detection-evasion or “undetectable” guide.

Better order

  1. Open the full export (not a cropped badge). Confirm attempt / paper identity.
  2. Read the legend and coverage once; note what is excluded (e.g. bibliographies on some surfaces).
  3. Import or align the report against your DOCX so flagged spans are addressable in order.
  4. Rewrite only highlighted continuous prose. Freeze quotations, citation fields, numbers, tables, and page layout.
  5. Diff the changed paragraphs against the original; refresh citation links in a copy if your manager uses fields.

Why whole-file rewrites waste a pass

International students often panic-polish every paragraph. That can scramble Zotero/EndNote fields and still leave the dense flagged body untouched. Targeting the report’s highlights keeps evidence intact while you revise the prose the model actually scored.

What this is not

  • Not a guarantee the next AI percentage will drop or clear.
  • Not a claim that HumanPen (or any tool) is undetectable or bypasses Turnitin.
  • Not a substitute for your course’s integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net is built for document-level revision against a detector report: work the flagged passages, aim to keep citations and layout. Complementary to guides such as reading the report before you cut. No promised next percentage.

Remember

  • Import the report; don’t rewrite blind.
  • Flagged continuous prose first—not the whole file.
  • Freeze citations, numbers, formulas, and layout.
  • Honest tools do not promise a clean next card.
