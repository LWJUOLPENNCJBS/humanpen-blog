保存检测导出时文件名立刻带上 attempt ID

Charles Li / HumanPen

门户下载常叫 Report.pdf 或 Download.pdf。重交两次后，桌面三个同名文件，办公室谈话打开错的那份。办法无聊但可靠：文件一落地就改名，写上 attempt ID，至少写上报告日期。

这与先确认 attempt ID、与索取完整导出、与裁切藏掉 attempt ID、与会面带同一文件、与改写前盖时间戳、与两份导出并排都不同。这里的素养动作很具体：进堆之前，文件名先带上 attempt ID（或日期）。

本文是检测器报告素养。不承诺分数，也不是规避指南。

更好的顺序

  1. 下载你关心的那次 attempt 的完整导出。
  2. 从首页或门户卡片读出 attempt ID（若可见，还有产品/版本）。
  3. 立刻改名，例如 课程_AI导出_attempt-48219_2026-10-14.pdf。
  4. 与带同一 ID 记号的匹配提交文件放在一起。
  5. 会上打开这对具名文件——不要从下载文件夹随便点一个 Report.pdf。

为什么通用文件名会失败

印度与东南亚英授项目的导师依据的是某一次 attempt。若你屏幕上是另一份导出，片段与百分比会对不上他们的门户。清晰文件名是流程卫生：避免争错 PDF，也避免重跑混在一起。

这不是什么

  • 不保证下一张徽章会清零。
  • 不是建议改 PDF 内容——只改文件名与归档。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持在你基于正确具名的 attempt 导出时，对照报告做文档级修订。不保证下一个百分比。

记住

  • 一下载就改名——文件名含 attempt ID。
  • 一堆 Report.pdf ≠ 开会可用。
  • 导出 + 提交用同一 ID 记号成对。
  • 诚实工具不承诺下一张干净卡片。
