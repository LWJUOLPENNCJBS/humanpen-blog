Cantumkan attempt ID di subjek email sebelum membahas flag

Charles Li / HumanPen

Subjek seperti “AI 87%” menyebar lebih jauh dari attempt yang dimaksud. Tanpa ID di subjek, balasan memperdebatkan lencana yang mungkin milik berkas lain.

Catatan ini melanjutkan literasi laporan detektor. Tidak menjanjikan kelulusan. Hanya meminta attempt ID di subjek sebelum diskusi.

Mengapa subjek dulu

Selaraskan dengan halaman attempt portal. Lampirkan export. Nama alat dan cakupan di baris pertama badan—jangan terkubur di bawah screenshot.

Utas email untuk logistik—bukan putusan.

Empat langkah

  1. 1. Salin attempt ID dari portal atau header export.
  2. 2. Subjek: kode mata kuliah + attempt ID (persen opsional, jangan sendirian).
  3. 3. Baris 1 badan: alat/versi + cakupan; lampirkan export penuh.
  4. 4. Tawarkan baca bersama singkat bila perlu—jangan jual jaminan lolos.

HumanPen dan ingat

HumanPen (https://humanpen.net) dapat menggambarkan impor laporan dan mengedit rentang ditandai dengan sitasi tetap. Tidak menjual peringkat atau kelulusan.

Ingat: ID di subjek; lencana bukan putusan.

Ingat

  • Attempt ID di subjek
  • Export terlampir
  • Persentase tidak sendirian di judul
  • HumanPen adalah bantuan alur kerja, bukan tiket lolos
