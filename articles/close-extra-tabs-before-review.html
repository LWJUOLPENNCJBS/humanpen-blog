Close every extra tab before flag review—keep only export and portal

Charles Li / HumanPen

A crowded tab bar feels like homework done. Mid-review you click an old report or draft and argue about a file nobody scored. Before the slot, close every extra browser and editor tab—keep only the scored export and the portal attempt page.

This is distinct from one-pdf-window-during-review (one export window while talking), from full-screen-export-during-review, from open-portal-beside-email, from freeze-draft-before-office-hours, from dont-edit-while-screensharing, from mute-chat-during-flag-review, and from bookmark-export-url-before-reply. Here the literacy move is concrete: pre-review tab hygiene—export + portal only.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. List what you need: scored export + portal attempt page (and maybe your notes pad).
  2. Close all other LMS tabs, old exports, drafts, and chat windows.
  3. Pin or bookmark the two keepers so they are hard to lose.
  4. Join the meeting only after the bar is clean.
  5. If you reopen something mid-slot, say aloud that it is not the scored pair.

Why extra tabs derail

Tutors in India and Southeast Asia English-medium programs follow your shared view. An old attempt badge beside a new draft looks like “detection changed.” Usually the wrong tab was still open from yesterday.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a ban on reopening a second scored export later for a planned compare.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report after a review that started with a clean tab bar on the named attempt. No guaranteed next percentage.

Remember

  • Close extra tabs before review.
  • Keep only scored export + portal attempt.
  • Old tabs → wrong-file arguments.
  • Honest tools do not promise a clean next card.
