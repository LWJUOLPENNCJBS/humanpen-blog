HumanPen Citation Fix is not reference verification: two different jobs for one manuscript

"Fix my citations" can mean two things, and they are not the same job. The first means change the style: move from one reference format to another, reorder fields, adjust punctuation, keep the wording. The second means check the references: are these sources real, are all of them present, does every in-text citation have a match. A tool can be good at one and silent on the other. This page separates them so you know which pass you are buying.

HumanPen's public pages describe both, but in different places and with different language. Citation Fix is listed among the document tools alongside Condense and Translate. The Start Project review example states that all eleven references were found, one by one. Those statements describe different operations: a conversion on a document, and a verification step on a delivered project. Conflating them leads to the wrong expectation.

The split is worth making explicit because search results and feature lists put both under "citation tools". A reference manager that de-duplicates entries is doing verification-adjacent work. A style converter is doing formatting work. Neither is a substitute for reading the source.

What a style conversion does

A style conversion is mechanical. It takes the information you already have and re-expresses it in another convention: author and year move position, titles change case, journal names are abbreviated or expanded, punctuation changes, and the in-text markers are updated to match. The words of your sentences do not change, and neither do your results.

That mechanical nature is a feature. It means the operation is predictable and you can check it by eye. Pick one reference you know well and look at it after the pass. If the author, year, title and source are all still there and only the arrangement changed, the conversion did its job. If an author disappeared or a year shifted, that is a conversion error, not a verification signal.

HumanPen lists Citation Fix among its document tools. The broader claim about protected elements on the humanizer page is also relevant to a converted document: numbers, units, formulas, citations, terminology and claim strength are described as kept. A style pass that quietly changed a year would violate that principle. It is reasonable to hold a conversion to the same standard.

What verification actually checks

Verification asks a different question: is each cited source real, and does it say what the sentence claims? The Start Project review example is specific about the first half. It states that all eleven references were found, one by one, as part of an independent review in which the primary endpoint matched, every analysis population added up and a clean rerun reproduced the results. "Found one by one" is a claim about locating each source, not about the quality of its content.

That precision matters. A reference can be found and still be misused. A paper exists, the DOI resolves, the author list is right, and yet the sentence cites it for a conclusion it did not reach. No style conversion detects that, and a presence check does not either. It remains a reading job. The value of "found one by one" is that it removes one class of failure: the invented or unreachable source.

This is also why a verification step belongs where the sources are being read. In the Start Project workflow, literature search is described with PubMed queries and DOI checks, and the evidence table is built from the papers. Verification at that stage has the source in hand. Verification after a style conversion has only the formatted string.

The order that avoids rework

Do the verification first and the conversion second. If a cited source does not exist, converting its citation to another style produces a tidy-looking fabrication. If a source exists but does not support the sentence, formatting it correctly makes the error harder to notice, not easier. A style pass is the last mechanical step before submission, not the first.

A workable sequence looks like this. Read each source and note the claim it supports. Confirm that the reference list and the in-text markers refer to the same set. Resolve any missing or unreachable source while you still have time to replace it. Then run the style conversion. Then re-read the reference list once, because a conversion can introduce its own small errors even when the underlying sources are sound.

If the target journal changes its citation style at revision, you only need the last two steps. That is the case where a converter earns its keep: the sources have already been checked, and only the arrangement has to change. Keeping verification and conversion in separate passes is what makes a revision quick.

Where HumanPen fits, and where it stops

HumanPen offers both a document tool for Citation Fix and a project workflow in which references are checked. The document tool is the right shape for a style change on a manuscript you already trust. The project workflow is the right shape when the literature itself needs to be searched, read, tabulated and checked as part of a larger analysis or draft.

Neither replaces a reference manager. If you need a shared library that stores metadata and keeps a live link between markers and bibliography, use one. HumanPen's statements about citations are about keeping them intact during a rewrite and about finding the sources in a supplied deliverable. That is a narrower and more testable promise.

The boundary is worth stating plainly: a tool that keeps your citations untouched is useful precisely because it does not reinvent them. A tool that reports all references found has told you something concrete about presence. Neither has told you that a citation is appropriate, and you should not ask them to.

A short checklist before you submit

Open the reference list and count the entries. Open the text and confirm every marker has a matching entry. Pick three sources you know and verify the author, year and claim. Search one DOI. Then run the style conversion and repeat the count. If the counts match and the three spot checks pass, the mechanical layer is done and the remaining judgement is yours.

If a project is involved, use the revision path rather than editing the file in place. The scope is explained before work starts, a new version is delivered and past versions are kept. That record is useful when a co-author asks why a reference changed.

Frequently asked questions

Does Citation Fix check whether a source exists?

The document tool is a style-conversion surface. The Start Project review example separately states that all eleven references were found, one by one. Those are different operations and should not be assumed to be the same.

Will a citation pass change the wording of my paper?

No. Citations are listed among the elements kept untouched, alongside numbers, units, formulas, terminology and claim strength. A style conversion changes the arrangement of the citation, not the sentence.

What does "found one by one" actually confirm?

It is a statement from the independent-review example that each reference in the delivered work was located. It is not a claim that each source supports the sentence citing it.

Should I verify before or after converting the style?

Before. Removing an invented or unreachable source is more useful than formatting it neatly, and a conversion is the cheaper pass to repeat later.

Can HumanPen replace my reference library?

No. It preserves citations in a document and can check references in a delivered project, but maintaining a shared library is a different job.
