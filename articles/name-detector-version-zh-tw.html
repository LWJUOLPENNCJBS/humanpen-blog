討論標記時寫清檢測產品名與版本

Charles Li / HumanPen

只說「AI檢測器標了我」幾乎永遠不夠。導師需要產品名以及版本、構建號或報告/attempt 日期。缺了這些，你可能在爭另一套工具、舊的 LMS 整合，或一次圖例已變的重跑。

這與「一個檢測器不夠」、與確認 attempt ID、與索取完整匯出、與兩份匯出並排、與評分標準與匯出並排、與改寫前蓋時間戳、與改寫前對齊圖例都不同。這裡的素養動作很具體：爭論片段前，先寫清產品名 + 版本/日期。

本文是檢測器報告素養。不承諾分數，也不是規避指南。

更好的順序

  1. 按入口或匯出頁眉原樣抄下產品名。
  2. 記下版本、構建、模型標籤，或至少報告日期／attempt 時間戳。
  3. 把 attempt ID 與這一對資訊放在一起，避免與重跑混在一起。
  4. 郵件或面談先寫產品 + 版本/日期，再寫 % 與片段。
  5. 若出現第二套工具，分別點名——不要併成一句「AI檢測」。

為什麼籠統說會談空

印度與東南亞英授專案的學校可能換供應商、啟用 LMS 外掛或刷新報告模板。沒有產品/版本的截圖百分比，對不上政策、培訓或先例。寫清構建是流程清晰，不是迂腐。

這不是什麼

  • 不保證下一張徽章會清零。
  • 不是建議換檢測器直到看起來更友好。
  • 若已正式啟動誠信程序，不能替代該程序。

HumanPen

HumanPen（humanpen.net）支援在產品與 attempt 身分清楚後，對照具名報告做文件級修訂。不保證下一個百分比。

記住

  • 產品名 + 版本/日期——不要只說「AI檢測器」。
  • 與 attempt ID 成對記錄。
  • 兩套工具 → 兩行具名。
  • 誠實工具不承諾下一張乾淨卡片。
