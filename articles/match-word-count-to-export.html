Match local word count or page length to the attempt export before the meeting

Charles Li / HumanPen

You open a doc that “feels” like the submission while the export shows a different length. Spans will not line up. Before you argue, compare word count or page length on your local file with the scored attempt export. A chunk missing or added usually means the wrong version—not a mysterious detector shift.

This is distinct from same-file-to-meeting (bring the scored file), from confirm-attempt-id-first, from save-export-with-attempt-id, from dont-rewrite-during-meeting, from office-hours-version-check, and from export-filename-checksum. Here the literacy move is concrete: length check local ↔ export before you talk spans.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Open the named export; note word count / pages / character count if shown.
  2. Open the local file you plan to share; run the same length metric in your editor.
  3. If they diverge by a large margin, stop—find the matching submission before the meeting.
  4. Only when lengths roughly match, proceed to attempt ID, spans, and your one question.
  5. Record both numbers in your takeaways so follow-ups stay on the same pair.

Why length mismatches fool people

Tutors in India and Southeast Asia English-medium programs work from the portal attempt. A shorter or longer local draft makes every highlight look “wrong,” which gets misread as detector instability. Length is a fast sanity check that the shared object is the same document.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a demand for exact character parity—look for large gaps that signal a different file.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report once you are editing the same-length attempt file. No guaranteed next percentage.

Remember

  • Match word count / pages local ↔ export.
  • Big length gap → wrong version, not “detection changed.”
  • Length check before span talk.
  • Honest tools do not promise a clean next card.
