Paste the attempt ID into the calendar invite for the flag meeting

Charles Li / HumanPen

An invite without the attempt ID forces everyone to guess which export to open.

This note continues detector-report literacy. It does not promise clearance. It asks you to put the attempt ID in the invite body.

Why the calendar line comes first

Copy the ID from the portal export into the invite description, and keep the export URL on the next line.

Calendar lines are logistics—not verdicts.

Four steps

  1. 1. Copy the attempt ID from the export.
  2. 2. Paste it into the calendar invite body.
  3. 3. Add the export URL under it.
  4. 4. Never sell a guaranteed pass.
