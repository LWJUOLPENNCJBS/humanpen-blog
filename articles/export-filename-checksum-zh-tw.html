用 attempt ID 命名 export 檔——能校驗就再記 checksum

Charles Li / HumanPen

export 會被轉發、改名，再和截圖混在一起。檔名嵌入 attempt ID 與日期，不必打開每個附件也能讀懂鏈條。

本文延續檢測器報告素養。它不承諾過檢。它要求在分數旁做好可留存的檔案衛生。

為什麼檔名重要

若可以，在準備表上記一短 checksum／雜湊。兩工具分歧時，保留兩份已命名 export。

coverage 與圖例說明仍要進案卷。

四步

  1. 1. 下載完整門戶 export。
  2. 2. 改名：工具_attemptID_YYYYMMDD。
  3. 3. 可選：在準備表記 checksum。
  4. 4. 檔案標好後再談分——從不推銷保證過檢。

HumanPen 與記住

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯 flagged span。它不賣排名或過檢。

記住：先命名，後爭論；兩工具檔案分開。

記住

  • 檔名帶 attempt ID+日期
  • checksum 可選但有用
  • 兩工具→兩份命名 export
  • HumanPen 是流程工具，不是過檢
