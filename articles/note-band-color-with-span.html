Note the legend band or color next to each quoted flagged span

Charles Li / HumanPen

Verbatim quotes without a band label flatten the report. A pale low-confidence mark and a dark high band look the same in plain text. When you quote a flagged span, write the legend band or color beside it—so later you don’t treat every highlight as the same strength.

This is distinct from quote-span-verbatim-in-notes (copy the wording), from read-legend-aloud-before-spans, from legend-before-rewrite, from light-band-uncertainty, from low-confidence-ai-highlight, from count-spans-before-debating, and from paste-export-link-not-badge. Here the literacy move is concrete: each quoted span carries its band/color tag in the notes.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Read the legend aloud once; keep its short labels handy (e.g. light / mid / dark).
  2. When you quote a span, add page locator + band/color in brackets.
  3. Example line: p.4 ¶2 [light / low confidence]: “…”
  4. Group follow-up rewrite plans by band—not by “all yellow looking the same.”
  5. If the export has no color key, note “band unknown” rather than inventing one.

Why the tag matters later

Tutors in India and Southeast Asia English-medium programs often revisit notes days later. Without band tags, every paste looks like equal weight. Tagging preserves the report’s strength language next to the exact string.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a claim that light bands are always harmless.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report when your notes still show which band each discussed span used. No guaranteed next percentage.

Remember

  • Note band/color with each quoted span.
  • Don’t flatten every highlight to the same strength.
  • Tag next to the verbatim quote + page.
  • Honest tools do not promise a clean next card.
