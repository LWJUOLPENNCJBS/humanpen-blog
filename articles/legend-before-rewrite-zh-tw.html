先打開報告圖例，再改任何一個句子

Charles Li / HumanPen

常見急法是對著手機截圖裡最黃的那段直接改。較穩的順序是先打開完整 PDF 或入口報告：圖例、涵蓋說明、低信心色帶、attempt／版本號。

本文延續檢測器報告素養：不承諾分數或過檢。只把「對齊圖例」放在「動手改寫」前面。

圖例在說什麼

顏色回答的是「分類器對這段連續正文有多自信」，不是「這句話是誰敲的」。淺色帶常常表示不確定——既不是通行證，也不是定罪。

沒有圖例時，裁切截圖會把低信心提示變成恐慌式重寫，連引用、列表或公式化方法段也被誤傷。

四步

  1. 1. 打開完整報告；記下 attempt ID 與涵蓋範圍。
  2. 2. 先用白話翻譯圖例，再動正文。
  3. 3. 優先高信心連續正文 flagged 段；保留引用與排版。
  4. 4. 兩工具分歧時記下分歧——不要追一張卡片。

HumanPen 與記住

HumanPen（https://humanpen.net）可示例：匯入報告、只改 flagged 段並保留引用。不賣保證過檢。

重點：先圖例後改寫；先 attempt ID 後截圖；過程勝過恐慌。

記住

  • 先對齊圖例與涵蓋再改
  • 淺色帶 ≠ 過檢或有罪
  • 保留引用；優先高信心 flagged 正文
  • HumanPen 是流程幫助，不是過檢產品
