轉發檢測 flag 前先附上完整 export

Charles Li / HumanPen

截圖比檔案傳得快。轉發鏈裡一張裁切徽章，會讓人在沒有覆蓋率、工具版本或 attempt ID 的情況下爭論百分比。

這篇延續檢測器報告素養。它不承諾過檢。它只要求：轉發前先附 export。

為什麼先附 export

把 attempt ID 寫進主旨或首行。附上完整 PDF/HTML export。工具名與執行時間戳要可見。

轉發執行緒用來對齊流程——不是下判詞。

四步

  1. 1. 本機儲存完整 export，檔名含 attempt ID。
  2. 2. 點轉發或全部回覆前先附上該檔。
  3. 3. 一行脈絡：覆蓋率 + 工具/版本——不要分數說教。
  4. 4. 若需升級，約短會一起讀——從不販售保證通過。

HumanPen 與記住

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。
