改写 flagged 段落后，参考文献表应原样回来

Charles Li / HumanPen

在 humanpen.net，当你改写被标出的连续散文后，参考文献 / 书目表应原样回来——顺序、标点、DOI 与条目正文。HumanPen 不是整篇洗稿，不会重排或「润色」文末引用。

这补充 freeze-citations-numbers-formulas（文内引用、数字、公式冻结）与 tables-captions-stay-intact（表格与题注保留）。它不同于 keep-citations-through-loop（循环纪律）、headings-styles-come-back / docx-layout-stays-intact（标题/样式/版式）、dont-wash-whole-document / only-flagged-continuous-prose / leave-unflagged-prose-alone（改写范围）、recheck-after-detector-update（厂商更新后复检）。本文点名参考文献表保真：润色 flagged 散文 → References / Works Cited / Bibliography 默认不动，除非该块本身就是被标出的连续散文。

不承诺下一次 AI%。不教「绕过检测 / undetectable」。学校政策仍决定是否结案。

为什么参考文献表必须原样

  1. 参考条目是结构化数据（作者、年份、题名、刊物、DOI）——洗它们容易弄断引用并制造 Similarity 噪声。
  2. 整篇「humanizer」常重排、改写或丢掉条目；这正是本文拒绝的失败模式。
  3. 文内引用记号与文末列表必须对齐；只改列表（或只改正文却不核对链接）都会拆散这对关系。
  4. 检测器与 Similarity 面板对待参考文献块往往不同于连续散文——不要「优化」列表指望更低 AI%。
  5. 诚实的文档级工具默认冻结列表，只动报告真正标出的连续散文。

可执行流程（对齐 HumanPen）

  1. 把 Turnitin / iThenticate AI 写作报告导入 HumanPen。
  2. 确认哪些跨度是 flagged 连续散文——以及 References 块本身是否被标出（通常不是）。
  3. 只改写 flagged 连续散文；冻结文内引用、数字、公式、术语、表格、题注与参考文献表。
  4. 导出后抽查：条目数、顺序、DOI/URL，以及文内键是否仍匹配列表。
  5. 下一轮重新导入新报告；若有免费轮，仍只作用于主页口径下仍被标出的散文——不是去重排 References。

这不是什么

  • 不保证下一次 AI% 或 Similarity% 会下降或过学校政策线。
  • 不是允许改写、翻译或「润色」书目表让它看起来更不像机器。
  • 不是「undetectable」、绕过，或隐藏署名的建议。
  • 不能替代文内记号的 freeze-citations-numbers-formulas，或图表的 tables-captions-stay-intact。

HumanPen 适合什么

HumanPen（humanpen.net）是文档级 AI 改写工具：导入报告、改 flagged 连续散文、尽量保引用、参考文献表与版式、按改写字计费，并在主页口径下对剩余 flagged 提供免费轮次。保住参考文献表是这种诚实的一部分——不是可选项。

记住

  • flagged 散文可以变；参考文献表应原样回来。
  • 补充 freeze-citations-numbers-formulas 与 tables-captions-stay-intact。
  • 不要为了追分去洗或重排 References。
  • 诚实工具不卖「绕过」或「undetectable」。
