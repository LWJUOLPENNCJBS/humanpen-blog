Confirm the attempt ID before office hours or a rewrite fight

Charles Li / HumanPen

Many heated meetings start on the wrong file. Before you defend a percentage or plan a rewrite, confirm which attempt or submission ID the school is looking at—and that your draft and report PDF match that ID. Debating Attempt 1 while the tutor has Attempt 2 open wastes the slot.

This is distinct from email-badge-vs-portal, resubmit snapshots, portal-vs-PDF coverage align, crops that hide IDs, screenshot≠case file, two disagreeing exports, office-hours version checks, and the two-paragraph similarity/AI script. Here the first move is simply: same ID, then talk.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Sixty-second confirm

  1. Ask (or read) the attempt / submission ID on the school’s screen or email.
  2. Open your portal row; copy the ID on your side.
  3. Open the report PDF header; check the same ID.
  4. Open the draft you will discuss; confirm it is the file for that attempt.
  5. Only then discuss bands, spans, or rewrites.

Why wrong-attempt debates happen

Students in India and Southeast Asia English-medium programs often resubmit quickly, forward old screenshots, or mix laptop folders. Tutors cannot map highlights to a draft if the IDs diverge. Fix identity first; content second.

What this is not

  • Not a guarantee the next badge will clear.
  • Not permission to ignore an older attempt if policy still counts it.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net helps you work from a full report against the matching document while keeping citations and layout—useful after IDs already agree. No guaranteed next percentage.

Remember

  • Confirm attempt ID first.
  • Draft + PDF + school row = same ID.
  • Wrong-attempt talk wastes office hours.
  • Honest tools do not promise a clean next card.
