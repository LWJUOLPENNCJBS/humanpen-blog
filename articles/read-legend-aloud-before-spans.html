Read the report legend aloud before you debate any highlighted span

Charles Li / HumanPen

Jumping straight to “this yellow paragraph” skips the key. Colors are not verdicts until you know the band. In office hours, read the report legend aloud first—what each color or confidence band means—before debating any span. “Yellow” alone is not a guilt label.

This is distinct from legend-before-rewrite (check the legend before you rewrite at home), from name-detector-version, from name-tool-version-in-reply, from pin-export-window-during-review, from one-pdf-window-during-review, from close-extra-tabs-before-review, and from full-screen-export-during-review. Here the literacy move is concrete: say the legend out loud in the meeting before span talk.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Open the scored export; find the legend / key / color guide.
  2. Read each band aloud with the tutor (e.g. light = low confidence, not “caught”).
  3. Write a one-line legend gloss in your notes under the attempt id.
  4. Only then walk page numbers and spans with that shared meaning.
  5. If the legend is missing, pause—ask for a full export before debating colors.

Why saying it aloud matters

Tutors in India and Southeast Asia English-medium programs and students often load different meanings onto the same hue. Reading the legend together locks a shared vocabulary so a pale band is not argued as hard guilt.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a claim that every pale span is harmless—only that color needs its key.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report after you and the tutor share the same legend reading. No guaranteed next percentage.

Remember

  • Read the legend aloud before span debate.
  • “Yellow” is not a guilt label without its key.
  • Shared legend → shared meaning.
  • Honest tools do not promise a clean next card.
