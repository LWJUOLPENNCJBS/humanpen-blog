改写 flagged span 前先记下时间戳

Charles Li / HumanPen

不少办公室先改写，事后再拼时间线。这会抹掉解释徽章变化最关键的一点：这份 export 是何时取出的。

本文延续检测器报告素养。它不承诺过检。它只要求改写前先打时间戳。

为什么先打戳

分类器会对表层编辑起反应。若同一张表上没有 attempt ID、coverage 与 export 时间，较低徽章会像「认错」，而不是流程。

若改后两工具仍分歧，保留两份带日期的 export。分歧是公正信号，不是竞赛。

四步

  1. 1. 抄下 attempt ID、coverage、图例说明与 export 时间戳。
  2. 2. 改前截图或导出门户页。
  3. 3. 只改 flagged span；保留引用。
  4. 4. 再导出并新打戳——从不推销保证过检。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑 flagged span。它不卖排名或过检。

记住：先打戳，再改写；两份 export 都留日期。

记住

  • 改写前先时间戳
  • 保留 attempt ID 与 coverage
  • 分歧带日期留档
  • HumanPen 是流程工具，不是过检
