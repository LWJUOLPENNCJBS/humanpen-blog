Bookmark the portal export URL before you reply to a flag

Charles Li / HumanPen

Flag emails often arrive with a cropped screenshot. Replying from the image alone loses the attempt ID and the live export link.

This note continues detector-report literacy. It does not promise clearance. It asks you to bookmark the portal export URL before any reply.

Why the bookmark comes first

Open the portal, open the scored attempt, copy the export URL, and save it as a browser bookmark named with the attempt ID. Reply with that URL—not with a phone photo of the badge.

Bookmarks are logistics—not verdicts.

Four steps

  1. 1. Open the portal beside the flag email.
  2. 2. Open the same attempt the email names.
  3. 3. Bookmark the export URL (name it with attempt ID).
  4. 4. Reply with the bookmark—never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: bookmark the export URL; badge is not a verdict.

Remember

  • Bookmark named with attempt ID
  • Reply with live export URL
  • Screenshot secondary
  • HumanPen is workflow help, not a pass
