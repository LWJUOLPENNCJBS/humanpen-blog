升级检测 flag 前先写日历备注

Charles Li / HumanPen

flag 传得比日历快。没有约谈时间的徽章转发，会把人逼进聊天里争百分比，而不是一起读 export。

本文延续检测器报告素养。它不承诺过检。它要求升级前先写日历备注。

为什么先写日历备注

把 attempt ID、coverage 与工具名贴进邀请。附上或链接完整 export。若随后改写，保留引用。

聊天只做后勤——不做判决。

四步

  1. 1. 约 15–20 分钟短会。
  2. 2. 日历备注：attempt ID + coverage + 工具／版本。
  3. 3. 附完整 export；截图居次。
  4. 4. 讨论流程下一步——从不推销保证过检。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑 flagged span。它不卖排名或过检。

记住：先日历，后升级；徽章不是判决。

记住

  • 先约再升级
  • 邀请里写 attempt ID
  • 优先 export 而非截图
  • HumanPen 是流程工具，不是过检
