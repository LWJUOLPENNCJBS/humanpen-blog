把 attempt ID 留在共享文档页眉

Charles Li / HumanPen

ID 只留在聊天里时，一滚动就不知道打开的是哪份 export。

本条延续检测器报告素养。它不承诺过检。它只要求把 attempt ID 留在共享文档页眉。

为什么页眉要一直可见

冻一行页眉：attempt ID + export URL。迟到的人也能对齐文件，不必翻整段线程。

页眉是后勤，不是裁决。

四步

  1. 1. 从门户 export 复制 attempt ID。
  2. 2. 贴进共享文档页眉。
  3. 3. 同一行或下一行附上 export URL。
  4. 4. 从不售卖保证过检。

HumanPen

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：ID 在页眉；徽章不是裁决。

记住

  • 页眉含 ID
  • 旁附 export URL
  • 聊天只作备份
  • HumanPen 是流程助手，不是通行证
