Name the detector tool and version in your flag reply

Charles Li / HumanPen

A reply that only says “the score was high” leaves everyone guessing which tool and build produced the badge.

This note continues detector-report literacy. It does not promise clearance. It asks you to name tool + version in the reply.

Why tool and version come first

Write the product name and the version or build string shown on the export. Paste the export URL beside that line. Screenshots without version text are secondary.

Naming the tool is logistics—not a verdict.

Four steps

  1. 1. Open the export and copy tool name + version.
  2. 2. Put both on the first line of the reply.
  3. 3. Attach or link the full export.
  4. 4. Never sell a guaranteed pass.

HumanPen and remember

HumanPen (https://humanpen.net) can illustrate importing a report and editing flagged spans with citations kept. It does not sell rankings or clearance.

Remember: name tool + version; badge is not a verdict.

  • Export link beside it
  • Screenshot secondary
