Put a named owner next to every action item before you leave

Charles Li / HumanPen

Action lists without names become everyone’s problem—and therefore nobody’s. Before you leave the room or close the call, write a named owner beside each action item—so follow-ups are not orphaned. For export review, that often means who owns the next rewrite pass on which spans.

This is distinct from schedule-followup-before-leave (book a time), from write-meeting-takeaways, from note-what-you-changed, from list-edits-chronologically, from same-file-to-meeting, and from ask-for-full-export. Here the literacy move is concrete: every action line carries a person name before you walk out.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. End with a short action list (rewrite spans, re-export, bring brief, email tutor).
  2. For each line, add a name in brackets—student, tutor, co-author, or “shared: A+B.”
  3. Example: “Rewrite §3 flagged spans [Maya] · Re-export PDF [Maya] · Confirm attempt ID on portal [Tutor R.]”
  4. If HumanPen is in the loop, note who runs the next rewrite pass against the same export.
  5. Read the list aloud once; fix any line still saying “we” with no name.

Why orphaned actions fail

Tutors in India and Southeast Asia English-medium programs leave crowded calls with shared notes. A floating “fix the highlights” has no owner. A named line keeps the export-review workflow moving between check-ins.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a way to dump work onto the tutor—name what each person actually owns.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report when your notes already say who owns the next rewrite pass. No guaranteed next percentage.

Remember

  • Name an owner on every action before you leave.
  • Orphaned “we’ll fix it” ≈ nobody fixes it.
  • Export review: who owns the next rewrite pass?
  • Honest tools do not promise a clean next card.
