匯入 PDF 報告與 DOCX 報告同一套流程

Charles Li / HumanPen

在 humanpen.net，匯入 Turnitin／iThenticate 類相似度或 AI 寫作報告時，無論匯出是 PDF 還是 DOCX，流程相同。HumanPen 把 flagged 跨度對應到你的草稿，並只改寫那些段落——不整篇洗稿。

這補充 import-report-rewrite-flagged-only、match-report-span-to-rewrite、docx-layout-stays-intact。它不同於門戶 vs PDF 覆蓋素養、recheck-after-detector-update、only-flagged-continuous-prose／leave-unflagged-prose-alone、pay-by-rewritten-words。本文點名報告匯入格式無關：PDF 或 DOCX 報告 → 同一套 flagged 跨度流程。

不承諾下一次 AI%。不教「繞過檢測／undetectable」。學校政策仍決定是否結案。

為什麼 PDF 與 DOCX 報告應同一套行為

  1. 學校門戶有的匯出 PDF、有的匯出 DOCX——學生不該學兩套產品。
  2. 工作單位是 flagged 連續散文跨度，不是報告檔案的容器格式。
  3. 整篇洗稿工具無視這一區別，把任何上傳都當成要 scrub 的文字。
  4. 誠實工具無論報告包裝如何，都把高亮對應到你的工作草稿（通常是 DOCX）。
  5. 第一次改寫前仍要確認 attempt 身分與覆蓋——格式不能為錯配 attempt 開脫。

可執行流程（對齊 HumanPen）

  1. 從 Turnitin 或 iThenticate 匯出 AI／相似度報告為 PDF 或 DOCX——門戶給什麼用什麼。
  2. 把該報告匯入 HumanPen；確認 attempt 身分與覆蓋匹配你要改的草稿。
  3. 讓 HumanPen 把 flagged 連續散文跨度對應到草稿；只改那些跨度。
  4. 保持引用、數字、公式、表格與版式；不要洗旁邊未標鄰居。
  5. 再匯出草稿；下一輪重新匯入新報告。若有免費輪，仍只作用於首頁口徑下仍被標出的散文。

這不是什麼

  • 不保證下一次 AI% 或 Similarity% 會下降或過學校政策線。
  • 不聲稱每種門戶 PDF 版式都解析得一模一樣——務必核對覆蓋與 attempt ID。
  • 不是「undetectable」、繞過，或隱藏署名的建議。
  • 不能替代 import-report-rewrite-flagged-only 的瞄準，或 match-report-span-to-rewrite 的跨度對齊。

HumanPen 適合什麼

HumanPen（humanpen.net）是文件級 AI 改寫工具：匯入報告（PDF 或 DOCX 包裝）、改 flagged 連續散文、盡量保引用與版式、按改寫字計費，並在首頁口徑下對剩餘 flagged 提供免費輪次。無論哪種包裝都是同一套流程——不是兩套產品。

記住
