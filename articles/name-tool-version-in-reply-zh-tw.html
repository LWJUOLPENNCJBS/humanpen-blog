回覆 flag 時寫明偵測工具名與版本

Charles Li / HumanPen

只說「分數很高」的回覆，讓大家猜不出是哪款工具、哪個 build 打的徽章。

這篇延續偵測器報告素養。它不承諾過檢。它只要求：回覆裡寫明工具名 + 版本。

為什麼先寫工具與版本

從 export 上抄產品名與版本/build 字串。把 export URL 放在同一行旁。沒有版本文字的截圖只作輔證。

寫明工具是流程對齊——不是下判詞。

四步

  1. 1. 打開 export，抄工具名 + 版本。
  2. 2. 寫在回覆第一行。
  3. 3. 附上或連結完整 export。
  4. 4. 從不售賣保證通過。

HumanPen 與記住

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住：寫明工具 + 版本；徽章不是判詞。

Remember

  • 第一行寫工具名與版本
  • 旁附 export 連結
  • 截圖只作輔證
  • HumanPen 是流程助手，不是通行證
