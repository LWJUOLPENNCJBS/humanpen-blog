共享螢幕前先固定 export 分頁

Charles Li / HumanPen

共享一個雜亂瀏覽器視窗時，export 會被其他分頁擋住。

本條延續檢測器報告素養。它不承諾過檢。它只要求共享前先固定 export 分頁。

為什麼先固定

固定能看見 attempt ID 的分頁，再開始共享。有人要 ID 時只切一次，不必翻找。

固定是後勤，不是裁決。

四步

  1. 1. 從邀請打開入口 export。
  2. 2. 固定該分頁。
  3. 3. 以 export 置頂開始螢幕共享。
  4. 4. 從不售賣保證過檢。

HumanPen

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。
