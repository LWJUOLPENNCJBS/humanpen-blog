把 attempt ID 同步進會議標題

Charles Li / HumanPen

標題只寫「flag 會議」時，大家仍不知道要開啟哪份 export。

本條延續檢測器報告素養。它不承諾過檢。它只要求把 attempt ID 同步進會議標題。

為什麼標題欄位重要

許多日曆在週視圖只顯示標題。把短 ID 後綴貼進去，點開前就能對齊檔案。

標題是後勤，不是裁決。

四步

  1. 1. 從入口 export 複製 attempt ID。
  2. 2. 把短 ID 後綴寫進會議標題。
  3. 3. 完整 ID 與 export URL 仍放在邀請正文。
  4. 4. 從不售賣保證過檢。

HumanPen

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。

記住：標題同步 ID；徽章不是裁決。

記住

  • 標題含短 ID
  • 正文含完整 ID
  • 下附 export URL
  • HumanPen 是流程助手，不是通行證
