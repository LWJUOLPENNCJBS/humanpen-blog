在 flag 线程里贴 export 链接，不要只贴徽章图

Charles Li / HumanPen

徽章 PNG 只显示一个数字，藏起 attempt ID、工具版本与高亮列表。

这篇延续检测器报告素养。它不承诺过检。它只要求：贴上实时 export URL。

为什么链接优于徽章图

复制被打分 attempt 的门户 export URL。把该 URL 贴进线程。截图只作辅证附件。

链接用来对齐流程——不是下判词。

Four steps

  1. 1. 在门户打开被打分的 attempt。
  2. 2. 复制 export URL。
  3. 3. 把 URL 贴进 flag 线程。
  4. 4. 从不售卖保证通过。

HumanPen

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：贴 export 链接；徽章不是判词。

Remember

  • 线程里放 export URL
  • 徽章图只作辅证
  • 通过链接可见 attempt ID
  • HumanPen 是流程助手，不是通行证
