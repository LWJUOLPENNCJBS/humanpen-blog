Tulis catatan kalender sebelum menaikkan flag detektor

Charles Li / HumanPen

Flag bergerak lebih cepat dari kalender. Lencana yang diteruskan tanpa waktu pertemuan mengajak orang berdebat persen di chat alih-alih membaca export bersama.

Catatan ini melanjutkan literasi laporan detektor. Tidak menjanjikan kelulusan. Meminta catatan kalender sebelum eskalasi.

Mengapa catatan kalender duluan

Tempel attempt ID, coverage, dan nama alat di undangan. Lampirkan atau tautkan export lengkap. Jaga sitasi jika ada rewrite.

Utas chat untuk logistik—bukan vonis.

Empat langkah

  1. 1. Buat pertemuan singkat (15–20 menit).
  2. 2. Catatan kalender: attempt ID + coverage + alat/versi.
  3. 3. Lampirkan export lengkap; screenshot sekunder.
  4. 4. Diskusikan langkah proses berikutnya—jangan jual jaminan lolos.

HumanPen dan ingat

HumanPen (https://humanpen.net) dapat mengilustrasikan impor laporan dan sunting flagged span dengan sitasi tetap. Tidak menjual peringkat atau kelulusan.

Ingat: kalender dulu; eskalasi kemudian; lencana bukan vonis.

Ingat

  • Jadwalkan sebelum eskalasi
  • Attempt ID di undangan
  • Export di atas screenshot
  • HumanPen adalah alur kerja, bukan lolos
