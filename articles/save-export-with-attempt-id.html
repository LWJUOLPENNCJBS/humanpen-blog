Save the detector export with the attempt ID in the filename

Charles Li / HumanPen

Portals often download as Report.pdf or Download.pdf. After two resubmits, your desktop has three identical names and you open the wrong one in office hours. The fix is boring and reliable: rename the file the moment it lands, embedding the attempt ID or at least the report date.

This is distinct from confirming attempt ID first, from asking for the full export, from crop-hides-attempt-id, from same-file-to-meeting, from timestamp-before-rewrite, and from two-exports-side-by-side. Here the literacy move is concrete: filename carries attempt ID (or date) before the file joins the pile.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Download the full export for the attempt you care about.
  2. Read attempt ID (and product/version if visible) from the first page or portal card.
  3. Rename immediately, e.g. Course_AI-export_attempt-48219_2026-10-14.pdf.
  4. Store it next to the matching submission file with the same ID token.
  5. Open that named pair in the meeting—not a random Report.pdf from Downloads.

Why generic names fail

Tutors in India and Southeast Asia English-medium programs work from a specific attempt. If your screen shows a different export, spans and % will not match their portal. A clear filename is process hygiene: it prevents arguing the wrong PDF and mixing re-runs.

What this is not

  • Not a guarantee the next badge will clear.
  • Not advice to edit the PDF contents—only the filename and your filing.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report once you are working from the correctly named attempt export. No guaranteed next percentage.

Remember

  • Rename on download—attempt ID in the filename.
  • Report.pdf piles ≠ meeting-ready.
  • Pair export + submission with the same ID token.
  • Honest tools do not promise a clean next card.
