先贴 flagged 原句块，再争分数

Charles Li / HumanPen

百分比在聊天里传得很快。Flagged 原句块不会——除非有人贴出来。先看到原句，约谈才更公平。

本文延续检测器报告素养。它不承诺过检。它要求先贴原句块，再谈分数。

为什么先贴原句

在原句旁写上 attempt ID、coverage 与图例说明。若两工具分歧，用同一文件时间戳贴两段原句。

改写放后面；若编辑，保留引用。

四步

  1. 1. 从 export 原样复制 flagged span。
  2. 2. 加上 attempt ID、coverage 与工具／版本。
  3. 3. 再讨论标题百分比。
  4. 4. 把修改当流程——从不推销保证过检。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑 flagged span。它不卖排名或过检。

记住：先原句，后分数；分歧必须对应到文本。

记住

  • 先贴原句再谈分
  • 旁注 attempt ID 与 coverage
  • 两工具→两段带日期原句
  • HumanPen 是流程工具，不是过检
