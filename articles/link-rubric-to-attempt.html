Link the rubric PDF to the same attempt ID as the export

Charles Li / HumanPen

A rubric without the matching attempt ID drifts into a different paper's criteria.

This note continues detector-report literacy. It does not promise clearance. It asks you to bind rubric and export by attempt ID.

Why the link comes first

Put the rubric PDF in the dated folder named with the attempt ID, or paste the same ID into the rubric filename. Open both beside the export.

Linking is logistics—not a verdict.

Four steps

  1. 1. Confirm the attempt ID on the export.
  2. 2. Name or tag the rubric PDF with that ID.
  3. 3. Keep both in the same evidence folder.
  4. 4. Never sell a guaranteed pass.

HumanPen
