郵件徽章 vs 入口匯出：先打開報告再爭論

Charles Li / HumanPen

LMS 郵件或通知卡片常顯示一個緊湊的 AI writing 百分比。打開同一 attempt 的入口匯出時，這個數字可能對不上。請帶著可見 attempt ID 的入口報告 PDF 爭論——不要只憑郵件徽章。

這與 LMS vs Messenger 截圖、與入口徽章對齊 PDF 覆蓋、與「截圖≠案卷」、與兩份工具匯出並排、與面談兩段話腳本都不同。這裡更窄：通知卡片 vs 入口匯出。

本文是檢測器報告素養。不承諾分數，也不是規避指南。

為什麼卡片會對不上

  • 郵件摘要可能滯後於重跑或後一次 attempt。
  • 卡片常只給摘要色帶，沒有完整連續正文高亮。
  • 教師郵件與學生入口視圖可能按不同時鐘刷新。
  • 沒有 attempt ID，你可能在比兩份不同提交。

印度與東南亞英授課程的學生常先憑郵件截圖升級衝突，卻還沒打開指導老師實際使用的入口 PDF。

改為這樣做

  1. 打開入口提交列；抄下 attempt／submission ID。
  2. 下載該 ID 對應的完整報告 PDF（或官方匯出）。
  3. 僅在 ID 一致後，再把郵件 % 與入口匯出比較。
  4. 辦公室談話帶 PDF——不要只帶郵件。

這不是什麼

  • 不保證入口數字會更低。
  • 不是建議忽略學校寄來的郵件。
  • 若已正式啟動誠信程序，不能替代該程序。

HumanPen

HumanPen（humanpen.net）支援對照完整報告處理文件並保留引用與排版——適合在入口匯出成為事實源之後使用。不保證下一個百分比。

記住

  • 郵件徽章 ≠ 最終入口匯出。
  • 爭論卡片前先有 attempt ID + PDF。
  • 滯後與摘要視圖解釋許多不一致。
  • 誠實工具不承諾下一張乾淨卡片。
