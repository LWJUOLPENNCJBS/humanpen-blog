门户与 PDF 对不上时：先对齐 attempt 身份，再查覆盖范围

Charles Li / HumanPen

交作业后，Moodle / Canvas / Blackboard 的门户徽章和下载 PDF常给出不同画面。群聊裁切传播更快。本文换一个切入点：在比较数字之前，先完成身份对齐。不承诺任何分数，也不是检测规避指南。

身份三件套

核对项门户 / 徽章下载 PDF
工具与 attempt工具名、submission / attempt 号、卡片时间封面文件名、报告 ID、导出时间
数字卡片上的整数或区间页眉 % / 区间 + 脚注
地图常只有色块分页高亮、灰带、排除块

身份不一致时，先停。你可能在比较两份不同材料——那是版本问题，不是「改分」阴谋。

身份一致后的覆盖素养

  1. 门户刷新摘要的时点，可能早于或晚于 PDF 导出。
  2. 卡片只汇总合格连续正文；PDF 标出表格、题注、附录、参考文献等排除块。
  3. 截图常裁掉工具名、报告 ID 或覆盖说明。
  4. 相似度与 AI writing 控件并排时，裁切容易合成一句谣言。

五步后再决定重写

  1. 记下徽章数字与 PDF 页眉数字及各自时间。
  2. 翻完 PDF：高亮 / 灰带 / 空白未评分各在哪。
  3. 对比 attempt 字数页数与 PDF 声称覆盖。
  4. 寻找门户从未显示的覆盖脚注。
  5. 书面问清：以实时卡片为准，还是以官方导出为准。

相似度仍不是 AI writing

低相似度不能抵消 PDF 里的 AI writing 指示；AI writing 指示也不能证明抄袭。覆盖错位会给两者都加噪声。

若学校已要求修改：把修改收束到将重检文件中的被标连续正文。冻结引用、表格和已核对事实，除非本身有错。文档级流程见 HumanPen。不承诺下一张门户卡片。

记住

  • 先身份，后覆盖，再措辞。
  • 徽章是标题；下载报告是讨论副本。
  • 任何诚实的工具都不该被说成「保证过关」。
