Tempel tautan ekspor—bukan gambar lencana—ke utas flag

Charles Li / HumanPen

PNG lencana menampilkan angka dan menyembunyikan attempt ID, versi alat, serta daftar span.

Catatan ini melanjutkan literasi laporan detektor. Tidak menjanjikan kelulusan. Meminta Anda menempel URL ekspor langsung.

Mengapa tautan mengalahkan lencana

Salin URL ekspor portal untuk attempt yang dinilai. Tempel URL itu ke utas. Simpan screenshot hanya sebagai lampiran sekunder.

Tautan adalah logistik—bukan vonis.

Four steps

  1. 1. Buka attempt yang dinilai di portal.
  2. 2. Salin URL ekspor.
  3. 3. Tempel URL ke utas flag.
  4. 4. Jangan jual jaminan lulus.

HumanPen

HumanPen (https://humanpen.net) dapat menunjukkan impor laporan dan mengedit span bertanda sambil menjaga sitasi. Tidak menjual peringkat atau kelulusan.

Ingat: tempel tautan ekspor; lencana bukan vonis.

Remember

  • URL ekspor di utas
  • Gambar lencana sekunder
  • Attempt ID terlihat lewat tautan
  • HumanPen bantuan alur kerja, bukan tiket lulus
