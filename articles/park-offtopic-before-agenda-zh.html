跑题先放进停车位，再回到议程

Charles Li / HumanPen

旁支争论偷走时钟，也模糊谁负责什么。话题一偏，先写进短「停车位」清单，再回到议程——行动负责人才清晰。Flag 复核里：attempt ID 与导出窗口未定前，先别追旁支争论。

这与每条待办具名负责人、与离开前先约跟进、与写会议要点、与 flag 复核时静音聊天、与先确认 attempt ID、与复核时钉住导出窗口都不同。这里的素养动作很具体：把跑题一行停住，再继续既定议程。

本文是检测器报告素养。不承诺分数，也不是规避指南。

更好的顺序

  1. 用一行点明议程（如：确认 attempt ID → 打开导出 → 列 flagged 片段）。
  2. 话一偏（「要不要换检测器…」「室友那例…」），写一条停车项。
  3. 口头说：「先停这儿——回到 attempt ID／导出。」
  4. 做完议程，再分流停车位（留下、另约、或丢掉）。
  5. 只给留下的项具名——不是通话中每个岔题都配负责人。

为什么停车位能保住负责人

印度与东南亚英授项目的导师时段很短。未停住的岔题会把「谁改 §3」拆成三场并行争论。停车位保护导出窗口议程，结尾的具名行动才说得通。

这不是什么

  • 不保证下一张徽章会清零。
  • 不是敷衍真实关切——停车项在议程后按时间再看。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持在 flag 复核议程已定下 attempt ID 与导出、再谈旁支之前，对照报告做文档级修订。不保证下一个百分比。

记住

  • 跑题先停；再回议程。
  • 先定 attempt ID／导出，再追旁支。
  • 停车位在核心复核之后分流——不是当中。
  • 诚实工具不承诺下一张干净卡片。
