會議筆記頂部先寫打分 attempt id

Charles Li / HumanPen

沒有 attempt 抬頭的好筆記很快會失效。談第一個高亮之前，把打分 attempt id 與匯出檔名寫在便條第一行。幾週後你仍知道談話說的是哪份檔——不是含糊的「那篇論文」。

這與討論前先問哪次 attempt、與先確認 attempt ID、與會後寫三行 takeaways、與郵件主旨寫 attempt ID、與入口標籤貼便條、與升級前資料夾日期戳、與開會帶列印匯出都不同。這裡的素養動作很具體：談任何高亮前，用 attempt id + 匯出檔名給筆記加抬頭。

本文是檢測器報告素養。不承諾分數，也不是規避指南。

更好的順序

  1. 打開空白筆記頁；把 attempt id + 匯出檔名寫成標題行。
  2. 下面寫會面日期與導師姓名。
  3. 然後再記片段、頁碼與那一個問題。
  4. 同一抬頭複製進跟進日曆邀請。
  5. 日後改寫時，按該 id 打開筆記 + 匹配匯出。

為什麼抬頭勝過記憶

印度與東南亞英授專案的導師常連續開多個短時段。週二未標註的筆記會與週三的 attempt 糊在一起。一行 attempt 抬頭讓 takeaways 仍掛在打分檔上。

這不是什麼

  • 不保證下一張徽章會清零。
  • 若還沒人點名，不能替代當面問打分的是哪一次。
  • 若已正式啟動誠信程序，不能替代該程序。

HumanPen

HumanPen（humanpen.net）支援在筆記仍點明你們討論過的 attempt 時，對照報告做文件級修訂。不保證下一個百分比。

記住

  • 筆記頂部寫 attempt id + 匯出檔名。
  • 先抬頭，再談高亮。
  • 未標註筆記會糊掉談的是哪份檔。
  • 誠實工具不承諾下一張乾淨卡片。
