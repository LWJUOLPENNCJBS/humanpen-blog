Mantenga el attempt ID en el encabezado del doc compartido

Charles Li / HumanPen

Si el ID solo vive en el chat, el primer desplazamiento pierde qué export abrió.

Esta nota continúa la alfabetización del informe del detector. No promete aprobación. Pide mantener el attempt ID en el encabezado del doc compartido.

Por qué el encabezado sigue visible

Congelé una línea de encabezado con attempt ID y URL del export. Quien llega tarde puede emparejar el archivo sin buscar el hilo.

Los encabezados son logística—no veredictos.

Cuatro pasos

  1. 1. Copie el attempt ID del export del portal.
  2. 2. Péguelo en el encabezado del doc compartido.
  3. 3. Añada la URL del export en la misma línea o la siguiente.
  4. 4. Nunca venda un aprobado garantizado.

HumanPen

HumanPen (https://humanpen.net) puede ilustrar la importación de un informe y la edición de tramos marcados conservando las citas. No vende rankings ni aprobaciones.
