争论片段前，先礼貌索取完整检测导出

Charles Li / HumanPen

有时收件箱里只有裁切徽章或邮件百分比。仅凭这些争论「哪句标错了」通常无效——导师依据的是某次 attempt ID 的完整检测器导出 PDF，不是缩略图。

这与「截图≠案卷」、与裁切藏掉 attempt ID、与邮件徽章 vs 门户报告、与先确认 attempt ID、与两份导出并排、与改写前盖时间戳、与不要只改引言都不同。这里的动作很具体：争论片段前，先索取该次 attempt 的完整导出 PDF。

本文是检测器报告素养。不承诺分数，也不是规避指南。

更好的顺序

  1. 保留收到的徽章/邮件；若可见任何数字，记下 attempt 或提交 ID。
  2. 礼貌向学校或 LMS 联系人索取同一次 attempt ID 的完整检测导出 PDF（或门户链接）。
  3. 打开导出；对齐图例、覆盖范围与 attempt ID，再点名片段。
  4. 然后再讨论 flagged 连续正文——或准备办公室谈话短注。
  5. 若之后两套工具不一致，把两份完整导出并排放。

为什么礼貌索取很重要

印度与东南亚英授项目的导师通常打开诚信流程使用的同一门户 PDF。截图百分比看不到覆盖、图例或哪些片段被标。索取完整导出是流程素养，不是对抗——也能避免对着错误页面改写。

这不是什么

  • 不保证下一张徽章会清零。
  • 不是建议在 PDF 出现前拒绝沟通——保持礼貌并遵守校规。
  • 若已正式启动诚信程序，不能替代该程序。

HumanPen

HumanPen（humanpen.net）支持在你拿到完整导出后，对照报告做文档级修订。不保证下一个百分比。

记住

  • 徽章截图 / 邮件 % ≠ 完整导出。
  • 礼貌索取该 attempt ID 的 PDF（或门户视图）。
  • 先对齐导出，再争论片段。
  • 诚实工具不承诺下一张干净卡片。
