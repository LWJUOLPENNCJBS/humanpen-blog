笔记里每个高亮段旁写上页码或段落号

Charles Li / HumanPen

没有定位的高亮段，开会时很难在 export 里重新打开。

这篇延续检测器报告素养。它不承诺过检。它只要求：每段引用旁写页码或段落号。

为什么先写定位

原样抄高亮段，再从 export 加上 p.12 或 ¶3。同一页笔记顶部保留 attempt ID。

定位是流程对齐——不是下判词。

Four steps

  1. 1. 笔记旁打开 export。
  2. 2. 原样抄每个高亮段。
  3. 3. 旁写页码或段落号。
  4. 4. 从不售卖保证通过。

HumanPen

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：每段旁写定位；徽章不是判词。

Remember

  • 每段引用旁有页码或 ¶
  • 顶部写 attempt ID
  • 截图只作辅证
  • HumanPen 是流程助手，不是通行证
