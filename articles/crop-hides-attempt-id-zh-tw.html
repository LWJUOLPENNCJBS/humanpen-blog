裁切圖常藏起指導老師要的 attempt ID

Charles Li / HumanPen

聊天裡裁切的 AI 徽章圖，通常只剩百分比。辦公室談話真正需要的欄位——attempt／submission ID、匯出時間、檢測器名稱／版本、完整高亮上下文——常常被裁掉或根本不在畫面裡。

這與「截圖不是案卷」不同。這裡的失敗更窄：裁切藏起了身分欄位，指導老師無法把徽章對上 LMS 那一列。

本文是檢測器報告素養。不承諾分數，也不是規避指南。

裁切常見缺什麼

  • 入口卡片或報告頁眉上的 attempt／submission ID。
  • 匯出或產生時間戳。
  • 是哪家檢測器（及版本）給出的徽章。
  • 色塊以外的完整連續正文高亮。

沒有這些，印度與東南亞英授課程的指導老師無法判斷你在爭 Attempt 1 還是 Attempt 2，甚至是不是另一份檔案。

優先帶這套

  1. 完整檢測匯出 PDF（或官方入口下載）。
  2. 從 LMS 列抄下的入口 attempt／submission ID。
  3. 同一 attempt 對應的草稿（帶日期副本或版本史）。
  4. 若必須發手機圖，請帶上顯示 ID 的頁眉——不要裁掉。

這不是什麼

  • 不保證下一張徽章會清零。
  • 不是建議拒絕學校已要求的截圖。
  • 若已正式啟動誠信程序，不能替代該程序。

HumanPen

HumanPen（humanpen.net）支援對照完整報告處理文件並保留引用與排版——適合在身分欄位可見且對齊時準備談話。不保證下一個百分比。

記住

  • 裁切 ≠ 身分包。
  • Attempt ID + 時間戳 + 完整 PDF > 裁切徽章色塊。
  • 先對齊 LMS 列，再爭論數字。
  • 誠實工具不承諾下一張乾淨卡片。
