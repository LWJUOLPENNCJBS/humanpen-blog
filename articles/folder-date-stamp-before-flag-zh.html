升级检测 flag 前先给证据文件夹打上日期戳

Charles Li / HumanPen

截图堆在桌面却没有家。没有日期的证据堆，很难证明大家讨论的是哪一次 attempt。

这篇延续检测器报告素养。它不承诺过检。它只要求：升级前先给文件夹打日期戳。

为什么先打日期戳

文件夹命名：YYYY-MM-DD + attempt ID。任何转发前先放进完整 export。若要开会，把大纲条款 PDF 放旁边。

文件夹用来对齐流程——不是下判词。

四步

  1. 1. 新建文件夹：日期 + attempt ID。
  2. 2. 把完整 export（及工具/版本备注）放进去。
  3. 3. 开会需要时再加大纲/评分标准。
  4. 4. 升级时附上该文件夹链接——从不售卖保证通过。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：先日期戳；徽章不是判词。

记住

  • 文件夹含日期与 attempt ID
  • 升级前先放 export
  • 截图只作辅证
  • HumanPen 是流程助手，不是通行证
