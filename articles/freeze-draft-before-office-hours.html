Freeze the editable draft before office hours—talk from the export only

Charles Li / HumanPen

Leaving the .docx open while you “just explain” is how you drift off the scored file. Before the meeting, freeze the editable draft: Save As a dated copy, set read-only, or close the editor. In the slot, open only the already-exported attempt PDF/HTML that matches the portal attempt id.

This is distinct from dont-rewrite-during-meeting (no live rewrite mid-talk), from match-word-count-to-export, from same-file-to-meeting, from confirm-attempt-id-first, from office-hours-version-check, and from timestamp-before-rewrite. Here the literacy move is concrete: lock the editable file first so the talk can only run on the frozen export.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Save As / read-only / close the editable draft before you join.
  2. Open the named attempt export (PDF/HTML) that matches the portal attempt id.
  3. Keep notes in a separate scratch pad—not typed into the scored file.
  4. Talk spans against the export only; schedule rewrite after takeaways.
  5. Re-open the editable copy only after the meeting ends.

Why an open editor fuels myths

Tutors in India and Southeast Asia English-medium programs share one object: the portal attempt. Typing while talking creates a moving document that never matched the badge. Students then say “detection moved”—usually they drifted off the scored file mid-slot.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a ban on jotting tutor suggestions—use a separate pad.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report after the meeting, on the frozen attempt you discussed. No guaranteed next percentage.

Remember

  • Freeze the editable draft before office hours.
  • Talk from the matching attempt export only.

  • Honest tools do not promise a clean next card.
