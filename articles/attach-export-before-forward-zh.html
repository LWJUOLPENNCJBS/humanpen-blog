转发检测 flag 前先附上完整 export

Charles Li / HumanPen

截图比文件传得快。转发链里一张裁切徽章，会让人在没有覆盖率、工具版本或 attempt ID 的情况下争论百分比。

这篇延续检测器报告素养。它不承诺过检。它只要求：转发前先附 export。

为什么先附 export

把 attempt ID 写进主题或首行。附上完整 PDF/HTML export。工具名与运行时间戳要可见。

转发线程用来对齐流程——不是下判词。

四步

  1. 1. 本地保存完整 export，文件名含 attempt ID。
  2. 2. 点转发或全部回复前先附上该文件。
  3. 3. 一行上下文：覆盖率 + 工具/版本——不要分数说教。
  4. 4. 若需升级，约短会一起读——从不售卖保证通过。

HumanPen 与记住

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：先附件，再转发；徽章不是判词。

记住

  • 转发前先附 export
  • 文件名与主题写 attempt ID
  • 截图只作辅证
  • HumanPen 是流程助手，不是通行证
