Preserve the reference list after flagged-prose rewrites

Charles Li / HumanPen

On humanpen.net, after you rewrite flagged continuous prose, the bibliography / reference list should come back intact—order, punctuation, DOIs, and entry text. HumanPen is not a whole-document wash that reshuffles or “improves” citations in the back matter.

That complements freeze-citations-numbers-formulas (in-text cites, numbers, formulas stay fixed) and tables-captions-stay-intact (tables and captions stay). It differs from keep-citations-through-loop (loop discipline), headings-styles-come-back / docx-layout-stays-intact (heading/style/layout fidelity), dont-wash-whole-document / only-flagged-continuous-prose / leave-unflagged-prose-alone (rewrite scope), and recheck-after-detector-update (fresh report after vendor change). This note names reference-list preservation: polish flagged prose → leave References / Works Cited / Bibliography alone unless that block itself was flagged continuous prose.

No promised next AI%. No “bypass detector” or “undetectable” claim. School policy still owns clearance.

Why the reference list must stay intact

  1. Reference entries are structured data (author, year, title, venue, DOI)—washing them invites broken cites and Similarity noise.
  2. Whole-doc “humanizers” often reorder, rephrase, or drop entries; that is the failure mode this note rejects.
  3. In-text citation tokens and the back-matter list must stay aligned; rewriting only the list (or only the prose without checking links) breaks that pair.
  4. Detectors and Similarity panels often treat reference blocks differently from continuous prose—do not “fix” the list hoping for a lower AI%.
  5. Honest document-level tools freeze the list by default and only touch continuous prose that the report actually marked.

Practical workflow (aligned with HumanPen)

  1. Import the Turnitin / iThenticate AI writing report into HumanPen.
  2. Confirm which spans are flagged continuous prose—and whether the References block itself is flagged (usually it is not).
  3. Rewrite only flagged continuous prose; freeze in-text citations, numbers, formulas, terminology, tables, captions, and the reference list.
  4. After export, spot-check: entry count, order, DOIs/URLs, and that in-text keys still match the list.
  5. Re-import a fresh report for the next round; free rounds (if any) still apply only to still-flagged prose under the homepage framing—not to reshuffling References.

What this is not

  • Not a guarantee the next AI% or Similarity % will drop or clear school policy.
  • Not permission to rewrite, translate, or “style” the bibliography to look less machine-like.
  • Not “undetectable,” bypass, or advice to hide authorship.
  • Not a substitute for freeze-citations-numbers-formulas on in-text tokens, or for tables-captions-stay-intact on figures.

Where HumanPen fits

HumanPen at humanpen.net is a document-level AI revision tool: import the report, rewrite flagged continuous prose, preserve citations, reference lists, and layout where possible, bill by rewritten words, and offer free rounds on remaining flags under the homepage framing. Preserving the reference list is part of that honesty—not an optional extra.

Remember

  • Flagged prose may change; the bibliography should come back intact.
  • Complements freeze-citations-numbers-formulas and tables-captions-stay-intact.
  • Do not wash or reshuffle References to chase a score.
  • Honest tools do not sell “bypass” or “undetectable.”
