Don’t panic-rewrite only the introduction

Charles Li / HumanPen

When an AI writing report arrives, many students polish the opening paragraphs and resubmit—while the flagged continuous-prose spans in the body stay almost unchanged. That panic-intro pass usually wastes an attempt. Edit the sections the report actually marked.

This is distinct from “rewrite loops are not guilt,” from building a flagged-span checklist, from triaging which sentences matter, from noting what you changed afterward, and from stamping a timestamp before rewrite. Here the anti-pattern is concrete: intro-only rewrite while body highlights remain.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Open the full export; confirm attempt ID.
  2. List flagged continuous-prose spans in the body (not only page 1).
  3. Edit those spans against the list; keep citations intact.
  4. Touch the intro only if it was highlighted or truly unclear.
  5. Save a short “what changed” note with the draft trail.

Why intro-only fails

Tutors in India and Southeast Asia English-medium programs open the same highlights you saw. If body spans still match the old report, a shiny new introduction does not explain authorship. Estimators also often score continuous body prose more than a short hook.

What this is not

  • Not a guarantee the next badge will clear.
  • Not advice to ignore a poorly written intro that was marked.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report while keeping citations and layout—useful for body spans the export actually flagged. No guaranteed next percentage.

Remember

  • Don’t rewrite only the intro.
  • Body highlights first; checklist before resubmit.
  • Intro polish ≠ clearing marked spans.
  • Honest tools do not promise a clean next card.
