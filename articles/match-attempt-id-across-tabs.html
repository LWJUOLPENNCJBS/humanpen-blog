Match the attempt ID across email, portal, and notes tabs

Charles Li / HumanPen

Three tabs often show three different attempts. Debating mixed IDs wastes the meeting.

This note continues detector-report literacy. It does not promise clearance. It asks you to match the attempt ID first.

Why matching comes first

Read the ID in the flag email, open that exact attempt in the portal, and write the same ID at the top of your notes. Only then discuss spans.

Matching IDs is logistics—not a verdict.

Four steps

  1. 1. Copy attempt ID from the flag email.
  2. 2. Confirm the same ID in the portal export.
  3. 3. Write that ID on the notes tab.
  4. 4. Never sell a guaranteed pass.
