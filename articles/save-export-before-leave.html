Save the portal export to disk before you leave the flag review

Charles Li / HumanPen

A closed tab without a saved file forces everyone to re-hunt the attempt later.

This note continues detector-report literacy. It does not promise clearance. It asks you to save the export before you leave.

Why save comes first

Download or export the full report, name the file with the attempt ID and date, and drop it in the dated evidence folder. Then leave.

Saving is logistics—not a verdict.

Four steps

  1. 1. Confirm the attempt ID on screen.
  2. 2. Save/export the full report to disk.
  3. 3. Name the file with attempt ID + date.
  4. 4. Never sell a guaranteed pass.
