Teacher dashboard vs student report: not the same evidence pack

Charles Li / HumanPen

Office-hours arguments often start from mismatched screens: the tutor opens the instructor dashboard (speed grader, attempt list, badge column), while you forward a student-view PDF or WhatsApp crop. Those are related views—not always the same evidence pack. Treating them as identical is how “my number doesn’t match yours” fights begin.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Why the two views diverge

Instructor boards may show a condensed AI writing indicator per submission, filters, and class averages. Student exports may include legends, confidence bands, page-level highlights, and footnotes the board collapses. Processing state, attempt ID, and file name can sit in different corners—or only on one side.

Students in India and Southeast Asia often compare a tutor’s spoken “twenty-something percent” with a still-processing student card. That is two instruments at two times, not one shared screenshot.

Align before you argue

  1. Confirm attempt ID / file name / timestamp on both sides.
  2. Ask whether the tutor is reading the board badge or the full student export.
  3. Bring the same export the school’s policy cites (official download, not a crop).
  4. Separate similarity columns from AI writing columns—teacher boards often juxtapose both.

What mismatch is not

A mismatch is not automatic proof the tool is “broken,” nor proof you are “caught.” It is a reason to sync the evidence pack before revising or escalating.

Where HumanPen fits

HumanPen at humanpen.net helps once you have a stable student-side report to import and revise against. It does not replace aligning teacher-view vs student-view first, and it does not guarantee the next badge.

Remember

  • Teacher dashboard ≠ student report by default.
  • Sync attempt identity before comparing numbers.
  • Prefer full exports over crops in office hours.
  • Honest tools do not promise a clean next card.
