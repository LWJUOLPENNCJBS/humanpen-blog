跑題先放進停車位，再回到議程

Charles Li / HumanPen

旁支爭論偷走時鐘，也模糊誰負責什麼。話題一偏，先寫進短「停車位」清單，再回到議程——行動負責人才清晰。Flag 覆核裡：attempt ID 與匯出視窗未定前，先別追旁支爭論。

這與每條待辦具名負責人、與離開前先約跟進、與寫會議要點、與 flag 覆核時靜音聊天、與先確認 attempt ID、與覆核時釘住匯出視窗都不同。這裡的素養動作很具體：把跑題一行停住，再繼續既定議程。

本文是檢測器報告素養。不承諾分數，也不是規避指南。

更好的順序

  1. 用一行點明議程（如：確認 attempt ID → 打開匯出 → 列 flagged 片段）。
  2. 話一偏（「要不要換檢測器…」「室友那例…」），寫一條停車項。
  3. 口頭說：「先停這兒——回到 attempt ID／匯出。」
  4. 做完議程，再分流停車位（留下、另約、或丟掉）。
  5. 只給留下的項具名——不是通話中每個岔題都配負責人。

為什麼停車位能保住負責人

印度與東南亞英授專案的導師時段很短。未停住的岔題會把「誰改 §3」拆成三場並行爭論。停車位保護匯出視窗議程，結尾的具名行動才說得通。

這不是什麼

  • 不保證下一張徽章會清零。
  • 不是敷衍真實關切——停車項在議程後按時間再看。
  • 若已正式啟動誠信程序，不能替代該程序。

HumanPen

HumanPen（humanpen.net）支援在 flag 覆核議程已定下 attempt ID 與匯出、再談旁支之前，對照報告做文件級修訂。不保證下一個百分比。

記住

  • 跑題先停；再回議程。
  • 先定 attempt ID／匯出，再追旁支。
  • 停車位在核心覆核之後分流——不是當中。
  • 誠實工具不承諾下一張乾淨卡片。
