Buka jendela catatan di samping portal—bukan di belakangnya

Charles Li / HumanPen

Catatan di belakang portal menjadi tebakan dari ingatan. Jendela berdampingan menjaga attempt ID dan kutipan span terlihat.

Catatan ini melanjutkan literasi laporan detektor. Tidak menjanjikan kelulusan. Meminta tata letak berdampingan.

Mengapa di samping lebih baik

Letakkan ekspor portal di setengah layar dan catatan di setengah lain. Salin attempt ID dan span ke catatan saat keduanya terlihat.

Tata letak adalah logistik—bukan vonis.

Four steps

  1. 1. Bagi layar: portal | catatan.
  2. 2. Pastikan attempt ID sama di keduanya.
  3. 3. Kutip span ke catatan sambil melihat ekspor.
  4. 4. Jangan jual jaminan lulus.

HumanPen

HumanPen (https://humanpen.net) dapat menunjukkan impor laporan dan mengedit span bertanda sambil menjaga sitasi. Tidak menjual peringkat atau kelulusan.

Ingat: catatan di samping portal; lencana bukan vonis.

Remember

  • Jendela berdampingan
  • Attempt ID sama terlihat
  • Screenshot sekunder
