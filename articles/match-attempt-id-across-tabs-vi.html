Đối khớp attempt ID trên tab email, cổng và ghi chú

Charles Li / HumanPen

Ba tab thường hiện ba attempt khác nhau. Tranh luận ID lẫn sẽ phí cuộc họp.

Bài này tiếp nối năng lực đọc báo cáo máy dò. Không hứa đậu. Chỉ yêu cầu đối khớp attempt ID trước.

Vì sao đối khớp trước

Đọc ID trong email flag, mở đúng attempt đó trên cổng, và ghi cùng ID lên đầu ghi chú. Chỉ rồi mới bàn đoạn gắn cờ.

Đối khớp ID là hậu cần—không phải phán quyết.

Four steps

  1. 1. Sao chép attempt ID từ email flag.
  2. 2. Xác nhận cùng ID trên export cổng.
  3. 3. Ghi ID đó lên tab ghi chú.
  4. 4. Không bán đảm bảo đậu.
