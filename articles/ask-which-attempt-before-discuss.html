Ask which submission attempt was scored before you discuss any highlight

Charles Li / HumanPen

Jumping straight into “why is this paragraph flagged?” skips the shared object. Open with one question: which submission attempt was scored—id, timestamp, or filename. Until that is named, every highlight debate risks comparing the wrong file to the report.

This is distinct from confirm-attempt-id-first (check the id on your export before you act), from sticky-note-on-portal-tab, from subject-line-attempt-id, from save-export-with-attempt-id, from same-file-to-meeting, from one-question-per-meeting, and from freeze-draft-before-office-hours. Here the literacy move is concrete: ask which attempt was scored before any highlight or % talk.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. First spoken line: “Which attempt id / timestamp / filename was scored?”
  2. Open that matching export together; write the id in your notes.
  3. Only then walk spans, page numbers, and your one concrete question.
  4. If the tutor is unsure, pause—pull the portal attempt list before debating.
  5. Carry the same attempt name into takeaways and the follow-up invite.

Why “the paper” is too vague

Tutors in India and Southeast Asia English-medium programs often see several uploads. Debating highlights against an unnamed “paper” mixes attempt 2’s badge with attempt 1’s draft. Naming the attempt first keeps the shared evidence one document.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a substitute for confirming the id on your own export file afterward.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report once you and the tutor agree which attempt was scored. No guaranteed next percentage.

Remember

  • Ask which attempt was scored before any highlight talk.
  • “The paper” without an attempt name is too vague.
  • Name id / timestamp / filename first.
  • Honest tools do not promise a clean next card.
