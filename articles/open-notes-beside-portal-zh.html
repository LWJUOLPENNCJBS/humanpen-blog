把笔记窗口开在门户旁边，不要压在后面

Charles Li / HumanPen

笔记压在门户后面，容易变成凭记忆猜。并排窗口能同时看见 attempt ID 与高亮原文。

这篇延续检测器报告素养。它不承诺过检。它只要求：并排布局。

为什么旁边优于后面

屏幕一半门户 export，一半笔记。两边都可见时，把 attempt ID 与高亮段抄进笔记。

布局是流程对齐——不是下判词。

Four steps

  1. 1. 分屏：门户 | 笔记。
  2. 2. 两边确认同一 attempt ID。
  3. 3. 看着 export 把高亮段抄进笔记。
  4. 4. 从不售卖保证通过。

HumanPen

HumanPen（https://humanpen.net）可演示导入报告并在保留引用下编辑高亮段。它不卖排名或过检。

记住：笔记在门户旁；徽章不是判词。

Remember

  • 并排窗口
  • 同一 attempt ID 可见
  • 截图只作辅证
  • HumanPen 是流程助手，不是通行证
