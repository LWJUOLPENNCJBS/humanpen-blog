附件順序很重要：先大綱與 export，再徽章截圖

Charles Li / HumanPen

把徽章截圖放在郵件最前，會逼所有人先爭數字。先放政策與完整 export，對話才從證據開始。

本文延續檢測器報告素養。它不承諾過檢。它只要求更冷靜的附件順序。

為什麼順序會塑造約談

若兩工具分歧，附上同一 attempt ID 的兩份帶日期 export，並讓 coverage 與圖例可見。

截圖仍有用——只是不要當開場證物。

四步

  1. 1. 附件1：大綱 AI 條款（或註明缺失）。
  2. 2. 附件2：帶 attempt ID 的完整門戶 export。
  3. 3. 附件3：可選徽章截圖，標為次要。
  4. 4. 若隨後改寫，保留引用——從不推銷保證過檢。

HumanPen 與記住

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯 flagged span。它不賣排名或過檢。

記住：順序也是公正的一部分；截圖是輔助，不是案卷本身。
