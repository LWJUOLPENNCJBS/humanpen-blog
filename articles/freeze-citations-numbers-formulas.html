Freeze citations, numbers, and formulas while you rewrite flagged prose

Charles Li / HumanPen

Rewriting every token in a flagged span can scramble footnotes and equations the report never scored.

This note continues detector-report literacy for HumanPen document polish. It does not promise clearance or an undetectable rewrite. It asks you to freeze citations, numbers, and formulas.

Why freeze before polish

Lock bibliography keys, numeric results, and display math. Edit only the surrounding prose HumanPen highlights as flagged.

Freezing structure is logistics for evidence—not a verdict.

Steps

  1. 1. Import the AI writing / Turnitin-style export into HumanPen.
  2. 2. Mark citations, numbers, and formulas as frozen.
  3. 3. Rewrite flagged prose only.
  4. 4. Never sell a guaranteed pass.
