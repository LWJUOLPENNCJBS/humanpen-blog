Ask for the full detector export before arguing spans

Charles Li / HumanPen

Sometimes the only “evidence” in your inbox is a cropped badge or an email percentage. Arguing which sentences are wrong from that alone usually fails—because tutors work from the full detector export PDF for a specific attempt ID, not from a thumbnail.

This is distinct from “a screenshot is not the case file,” from cropped screenshots that hide the attempt ID, from email-badge vs portal report, from confirming attempt ID first, from putting two exports side by side, from stamping a timestamp before rewrite, and from not rewriting only the intro. Here the ask is concrete: request the full export PDF for that attempt before debating spans.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Keep the badge/email you received; note the attempt or submission ID if any digit is visible.
  2. Politely ask the school or LMS contact for the full detector export PDF (or portal link) for that same attempt ID.
  3. Open the export; align legend, coverage, and attempt ID before naming spans.
  4. Only then discuss flagged continuous-prose spans—or prepare a short office-hours note.
  5. If two tools disagree later, bring both full exports side by side.

Why a polite ask matters

Tutors in India and Southeast Asia English-medium programs usually open the same portal PDF their integrity process uses. A screenshot % does not show coverage, legend, or which spans were marked. Asking for the full export is process literacy, not confrontation—and it prevents rewriting against the wrong page.

What this is not

  • Not a guarantee the next badge will clear.
  • Not advice to refuse dialogue until a PDF appears—stay polite and on-policy.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report once you have the full export to work from. No guaranteed next percentage.

Remember

  • Badge screenshot / email % ≠ full export.
  • Ask politely for the PDF (or portal view) for that attempt ID.
  • Align export before arguing spans.
  • Honest tools do not promise a clean next card.
