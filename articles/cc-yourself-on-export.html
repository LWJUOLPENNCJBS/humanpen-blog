CC yourself when you download or forward the detector export

Charles Li / HumanPen

A good filename helps; a file that only lives in Downloads or a group chat does not. When the portal hands you the PDF—or you forward the badge email—CC your own address or drop it into a course folder the same minute. Later you need that exact attempt, not a screenshot buried in WhatsApp.

This is distinct from save-export-with-attempt-id (rename on disk), from open-portal-beside-email, from ask-for-full-export, from email-badge-vs-portal, from export-filename-checksum, and from calendar-note-before-flag. Here the literacy move is concrete: route a copy to yourself / a known archive as soon as the export exists.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. Download or open the full export for the attempt you care about.
  2. Rename with attempt ID if needed; then email it to yourself or save to a labeled course folder.
  3. If forwarding a badge email, CC yourself and keep the portal link in the body.
  4. Star or label that message so it is searchable before office hours.
  5. Bring that same routed copy—not a chat screenshot—to the meeting.

Why routing matters

Tutors in India and Southeast Asia English-medium programs expect the portal attempt. Students lose days hunting files shared only in chat. Self-CC / folder archive is process hygiene: same attempt, findable under stress.

What this is not

  • Not a guarantee the next badge will clear.
  • Not advice to spam the tutor—CC yourself, not the whole class list.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report once you can still open the archived export. No guaranteed next percentage.

Remember

  • CC yourself / archive folder—on download or forward.
  • Chat dumps ≠ meeting-ready export.
  • Naming helps; routing keeps it findable.
  • Honest tools do not promise a clean next card.
