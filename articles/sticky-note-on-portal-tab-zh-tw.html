爭徽章前先在入口標籤貼一張便利貼

Charles Li / HumanPen

聊天比標籤快。沒打開 attempt 頁就貼上百分比，會讓人臆造被打分的是哪份檔案。

這篇延續檢測器報告素養。它不承諾過檢。它只要求：先在入口標籤貼便利貼。

為什麼先貼便利貼

寫上 attempt ID、工具名與覆蓋率——或直接改瀏覽器標籤標題。讓 export 下載連結一鍵可及。

聊天用來對齊流程——不是下判詞。

四步

  1. 1. 打開入口 attempt 頁；確認 ID 與郵件徽章一致。
  2. 2. 便利貼或標籤標題：attempt ID + 覆蓋率。
  3. 3. 下一則回覆前先下載/附上完整 export。
  4. 4. 討論流程下一步——從不販售保證通過。

HumanPen 與記住

HumanPen（https://humanpen.net）可示範匯入報告並在保留引用下編輯高亮段。它不賣排名或過檢。
