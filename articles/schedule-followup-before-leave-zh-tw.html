離開面談前先約好下一次核對

Charles Li / HumanPen

許多會面以模糊的「改完再寄信給我」收場。沒有日曆上的時間，跟進就會沉入沉默。走出門前，先約好下一次核對——哪怕十分鐘線上——以便重開同一次 attempt 匯出與 takeaways。

這與會後寫 takeaways、與一場會一個問題、與按時間列編輯、與改後記下改了什麼、與會面帶同一檔、與索取完整匯出都不同。這裡的素養動作很具體：離開房間前，先排好下一次核對。

本文是檢測器報告素養。不承諾分數，也不是規避指南。

更好的順序

  1. 先把內容談收在一個已答或暫掛的問題上。
  2. 寫好三行 takeaways（約定／下次帶／片段仍開放）。
  3. 請約具體跟進時段——日期、時間、方式（辦公室／Zoom／郵件截止）。
  4. 寫入日曆，事件備註裡放 attempt ID 與匯出檔名。
  5. 若導師此刻無法預約，當天郵件提出兩個可選時間。

為什麼未排期的「以後」會失敗

印度與東南亞英授專案的導師要排隊列與批改。漂浮的「以後」沒有負責人。約好的時段讓對話留在同一條 attempt 時間線上，也避免你對著虛空改寫。

這不是什麼

  • 不保證下一張徽章會清零。
  • 不是逼導師超出政策的時間——禮貌地問能安排什麼。
  • 若已正式啟動誠信程序，不能替代該程序。

HumanPen

HumanPen（humanpen.net）支援在已排期的核對之間，對照報告做文件級修訂。不保證下一個百分比。

記住

  • 離開前先約跟進。
  • 未排期的「再看看」≈ 不會發生。
  • 日曆備註：attempt ID + 匯出檔名。
  • 誠實工具不承諾下一張乾淨卡片。
