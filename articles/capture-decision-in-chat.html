Capture each decision in chat in one sentence before moving on

Charles Li / HumanPen

Spoken decisions evaporate. When the room agrees, write that decision into the shared chat or notes in one sentence before you move on—so it isn’t lost in voice. Use the same habit after an AI-writing flag export: capture keep / rewrite / escalate in text before the next span.

This is distinct from confirm-owner-before-leave, from label-owner-on-each-action, from write-meeting-takeaways, from park-offtopic-before-agenda, from mute-chat-during-flag-review, and from note-what-you-changed. Here the literacy move is concrete: one written decision line at the moment it is made.

This note is detector-report literacy. It does not promise any score, and it is not a detection-evasion guide.

Better order

  1. When someone says “so we’ll…”, pause one beat.
  2. Type a single line: Decision: … (who / what / by when if known).
  3. Example after flag review: “Decision: rewrite §2–§3 flagged spans [Maya]; keep methods as-is; escalate only if attempt ID mismatches.”
  4. Paste into the shared chat or pinned notes thread; get a quick ack if needed.
  5. Then move to the next agenda item—don’t stack three verbal decisions unwritten.

Why voice-only decisions fail

Tutors in India and Southeast Asia English-medium programs juggle back-to-back slots. A keep/rewrite/escalate call that stays only in voice becomes three different memories by evening. One sentence in chat keeps the export-review trail honest.

What this is not

  • Not a guarantee the next badge will clear.
  • Not a full meeting transcript—one decision sentence is enough.
  • Not a substitute for a formal integrity process if one is opened.

Where HumanPen fits

HumanPen at humanpen.net supports document-level revision against a report when your chat already records which spans to keep, rewrite, or escalate. No guaranteed next percentage.

Remember

  • Write the decision in one sentence before moving on.
  • Voice-only ≈ forgotten by tonight.
  • Flag review: capture keep / rewrite / escalate in chat.
  • Honest tools do not promise a clean next card.
