Long documents: no word limit, original styling untouched, editable files out

Charles Li / HumanPen · long documents · 8 Nov 2026

The failure mode of long-document rewriting is never "the tool refused the file". It is a 100-page thesis that comes back with the heading numbering restarted, three tables re-flowed, and 41 footnotes renumbered. HumanPen takes DOCX, PPTX and TXT with no word limit and returns the file with its original styling untouched — but you still have to verify it, and the checklist below is how.

The rule: editable files in, editable files out. If a tool answers with a paste box, it is not a document tool — it is a text editor with extra steps, and it will cost you the formatting you already paid for.

Why "no word limit" changes the economics

Tools that meter by document push you into splitting the file — half a thesis now, half later. Splitting is where cross-references break and where the two halves drift apart in voice. A document-level pass on the whole file keeps the argument continuous, and because you are billed for the words actually rewritten, a targeted pass on flagged spans stays affordable even at 60,000 words.

The verification pass, in order

  1. Open the file, not a preview. Previewers hide exactly the details that break.
  2. Outline check. Heading levels and numbering identical to the version you sent.
  3. Table check. The three widest tables and any table with merged cells.
  4. Note check. First and last footnote; if they match, the middle almost always does.
  5. Break check. Chapter starts, appendix starts, and any deliberate page break you inserted.
  6. Read one rewritten paragraph aloud. If it does not sound like you, the rewrite over-corrected.

Long documents and detection reports

If a report covers the file, import it and let it decide the scope; a 100-page document usually has a small number of flagged spans, and rewriting everything is both expensive and unnecessary. Numbers, units, formulas, citations, terminology and claim strength stay exactly as they were — a long document is precisely where a silent change to one percentage would be hardest to catch.

FAQ

Is there really no word limit?

The product takes DOCX, PPTX and TXT with no word limit and returns the original styling untouched whatever the length. Verify the export anyway: length is where formatting bugs hide.

Can I send a 60,000-word thesis?

Yes. Because you are billed only for the words actually rewritten, a targeted pass on flagged spans is the affordable way to handle a file that size.

What if my footnotes renumber?

That is a formatting failure, not an acceptable side effect. Re-open the original and re-run the export; note it so it does not happen again on the next chapter.
